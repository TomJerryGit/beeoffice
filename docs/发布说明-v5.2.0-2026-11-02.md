## 本版新增
### Writer
- 页眉页脚：首页不同、奇偶页不同、页眉/页脚 Logo、应用到所有节；
- 页码：分节独立格式（起始页/阿拉伯/罗马/位置）；
- 题注升级为 Word `SEQ` 域；图表目录 `TOC \c "图"`；
- 交叉引用：标题书签 + `REF` 域 + DOCX 导入还原 `【见：标题】`；
- 图片：百分比裁剪、环绕方式（嵌入式/四周型/上下型/衬于文字下方）；
- 表格：跨页重复标题行。

### 蜜演
- 动画面板：CSS 选择器动画、进入/退出/强调、顺序/时长/延迟、切换效果库；
- 配置持久化到幻灯片 HTML 注释；
- 播放引擎注入选择器动画；
- PPTX 导出：页面切换、实验性逐元素动画（淡入/淡出/脉冲/滑入/缩放/抖动）、按点击逐步播放；
- 真实 PowerPoint/WPS 打开验证通过。

### PDF / 其他
- PDF 书签管理（增/删/改）、图片签名/图章、签名定位；
- 宏控制台（白名单命令 + JSONL 审计 + JSON 回放）；
- 数据工具箱、校对体检、投屏遥控（二维码 + 手机控制栏 + loopback）。

- 交叉引用仅按标题，导入还原为占位；
- 真机扫码按约定跳过。
