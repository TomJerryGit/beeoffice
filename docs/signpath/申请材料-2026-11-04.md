## 2. 为什么符合 Foundation 条件

- 公开 GitHub 仓库；
- MIT 开源许可证；
- 无广告、无捆绑、无恶意行为；
- 构建可复现：PyInstaller + Inno Setup，均在 CI 中完成；
- 愿意在 README/下载页标注：
  “Free code signing provided by SignPath.io, certificate by SignPath Foundation”。

## 3. 申请步骤（需人工）

1. 注册 SignPath 账号：https://signpath.org/
2. 打开 Foundation 申请页：https://signpath.org/foundation.html
3. 提交：
   - 仓库 URL；
   - MIT 许可证说明；
   - 维护者联系方式；
   - 构建工作流链接；
   - 需要的签名对象：`BeeOffice.exe`、`BeeOffice-Setup-*.exe`；
4. 等待审核（通常需要人工沟通）；
5. 审核通过后，在 SignPath 控制台创建：
   - Organization；
   - Project（关联仓库）；
   - Signing Policy（release）；
   - Artifact Configuration（见同目录文档）；
6. 把以下值配置到 GitHub：
   - Secrets：`SIGNPATH_API_TOKEN`
   - Variables：`SIGNPATH_ORGANIZATION_ID`、`SIGNPATH_PROJECT_SLUG`、`SIGNPATH_POLICY_SLUG`、`SIGNPATH_ARTIFACT_CONFIG_SLUG`

## 4. 审核通过后的发布流程

```text
构建 ZIP/安装器
   ↓
上传未签名产物到 SignPath
   ↓
SignPath 用 Foundation 证书签名
   ↓
下载签名产物
   ↓
校验 signtool /pa
   ↓
GitHub Release
```
