# BeeOffice 开发冻结公告

生效日期：2026-11-18  
冻结基线：v5.8.14（本地源码）  
冻结周期：至 Phase 1 门禁 G1 通过

## 冻结范围

- 不新增功能、页签、按钮、P2 能力；
- 不进行 UI 大改或非紧急重构；
- 不发布功能型 Beta；
- 只允许以下变更：

```text
P0 数据丢失 / 崩溃 / 安全
P1 真实语料保真缺陷
架构收敛（RFC 已批准）
签名/干净机/发布门禁
测试与文档
```

## 变更流程

1. 建 issue，标注 P0/P1 与影响模块；
2. 必须附复现样本或测试；
3. 核心开发自测 + 全量测试；
4. 涉及保真的变更必须跑 WPS 真实验收；
5. 每周五统一合并，禁止长期分支。

## 例外审批

以下必须经“阶段门禁评审”批准：

- 新依赖
- 数据结构/元数据 schema 变更
- 发布流程变更
- 功能恢复

## 退出条件

Phase 1 门禁 G1 全部满足后解除冻结：

- 真实语料往返 ≥85%
- OOXML schema 校验 100%
- 领域模型 v1 合并
- 签名流程可演示
- 干净机模板可用
