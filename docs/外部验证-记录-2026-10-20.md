## 1. 运行环境与隔离措施

1. 把 `beecmd.exe` 与 3 份真实业务表复制到仓库外目录 `C:\beeoffice_external_validation`；
2. 子进程环境：`PATH=C:\Windows\System32;C:\Windows`（**无 Python**）、`PYTHONPATH=`、`TEMP` 指向本地目录；
3. 从该目录直接运行 `beecmd.exe`，全程不启动 BeeOffice GUI；
4. 本机磁盘上确实还装有 Python 3.11 —— 这一点如实记录：这是**环境隔离**验证，
   不是“机器物理上没装过 Python”的验证；exe 为 PyInstaller onefile，运行不依赖该 Python。

## 4. 已知边界（如实）

- **同一台机器**：这是“本机隔离环境”验证，不是另一台物理机；本机磁盘上有 Python，
  但 PATH 被清空、exe 为自包含 onefile，运行不依赖该 Python；
- `md → docx/pdf` 不支持（依赖 Qt，exe 明确排除）；
- exe 未签名，SmartScreen 可能提示未知发布者；
- GBK 控制台下 emoji 显示为 `?`（`_make_console_safe` 的设计，不崩）；
- verify 的退出码 2 是**诚实的不一致报告**，本记录不把它算作通过项。
