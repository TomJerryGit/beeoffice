## 3. 正式证书配置步骤

1. 购买代码签名证书（推荐 EV 或至少 OV），获取 `.pfx`；
2. 将 PFX 放到安全路径，**不要提交仓库**；
3. 设置环境变量：
   ```powershell
   $env:BEEOFFICE_SIGN_PFX = "D:\secure\beeoffice.pfx"
   $env:BEEOFFICE_SIGN_PASSWORD = "***"
   ```
   或使用证书指纹（证书已导入 `Cert:\CurrentUser\My`）：
   ```powershell
   $env:BEEOFFICE_SIGN_CERT_SHA1 = "<thumbprint>"
   ```
4. 先签名主程序，再构建安装器，最后签名安装器：
   ```powershell
   python tools/sign_windows.py dist\BeeOffice\BeeOffice.exe
   python tools/build_installer.py --skip-build
   python tools/sign_windows.py release-archive\BeeOffice-Setup-v5.3.2.exe
   ```
5. 验证：
   ```powershell
   signtool verify /pa /v release-archive\BeeOffice-Setup-v5.3.2.exe
   ```

## 4. CI 配置

在 GitHub 仓库 Secrets 中设置：

| Secret | 内容 |
|---|---|
| `WINDOWS_CERT_PFX_BASE64` | PFX 文件的 Base64 |
| `WINDOWS_CERT_PASSWORD` | PFX 密码 |

工作流 `.github/workflows/release-windows.yml` 会：

1. 解码 PFX 到临时目录；
2. 设置 `BEEOFFICE_SIGN_PFX` / `BEEOFFICE_SIGN_PASSWORD`；
3. 调用 `tools/sign_windows.py` 签名 zip 与安装器；
4. 上传签名后的产物。
