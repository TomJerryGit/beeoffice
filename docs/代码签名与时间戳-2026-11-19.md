# 代码签名与时间戳记录

日期：2026-11-19  
脚本：`tools/sign_release.ps1`

## 当前证书

```text
Subject: CN=BeeOffice Local Test, O=BeeOffice, C=CN
Thumbprint: 0DD9413BDF9626F27D78E3A9AEC70C1E9E3CE8D8
NotAfter: 2028-11-04
HasPrivateKey: True
```

**这是本地测试证书，不是受信任的 CA 证书。**

## 已验证流水线

对 `BeeOffice.exe` 副本执行：

```text
signtool sign /sha1 <thumbprint> /fd SHA256 /tr http://timestamp.digicert.com /td SHA256
signtool verify /pa
```

结果：

```text
Successfully signed
STATUS=Valid
TIMESTAMP=DigiCert SHA256 RSA4096 Timestamp Responder 2026 1
```

## 结论

- **签名流水线可用**；
- **RFC3161 时间戳可用**；
- **本地证书只能用于验证流程，不能解决 SmartScreen/企业信任**；
- 正式发布必须采购受信任的 OV/EV 代码签名证书或 Azure Trusted Signing。

## 正式发布前必须做

1. 采购受信任证书；
2. 私钥放 HSM/云签名，禁止入仓库；
3. 签名 exe、安装器、附带 DLL；
4. 时间戳；
5. `signtool verify /pa`；
6. SmartScreen 状态记录；
7. 发布说明附证书指纹与 SHA256。

## 脚本用法

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/sign_release.ps1 `
  -AllowTestCert `
  -Files "dist\BeeOffice\BeeOffice.exe","release-archive\BeeOffice-Setup-vX.Y.Z.exe"
```

正式证书到位后去掉 `-AllowTestCert`。
