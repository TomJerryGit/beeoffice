# BeeOffice v5.7.0

发布日期：2026-11-17  
Release：https://github.com/TomJerryGit/beeoffice/releases/tag/v5.7.0  
发布状态：**Beta / Unsigned**（未签名；未做干净机验收；Win11 未验证）

## 重点更新（Wave 4：PPT P0）

### 幻灯片管理
- 缩略图/拖拽排序/新建/删除/重命名；
- 复制幻灯片；
- 隐藏幻灯片，缩略图标记 `[隐藏]`；
- 12 种版式。

### 设计/过渡
- 设计页签：设计面板、过渡、动画；
- 统一字体应用到预览；
- 过渡效果可应用到当前页或全部页。

### 画布编辑基础
- 预览元素拖动；
- Alt+滚轮调整宽度；
- Delete 删除元素；
- 画布撤销/重置；
- 覆盖仅作用于预览，不修改 Markdown 源。

### 放映/导出
- 从头开始、从当前开始；
- 演讲者视图、排练计时沿用已有；
- 20 页 PPTX 导出往返 20/20；
- PDF/HTML/图片/GIF 导出沿用已有。

### 工程化
- 全量测试 **1621 passed**；
- 安全扫描高危 0；
- 依赖锁与 CycloneDX SBOM 保持；
- CI 全量测试/安全扫描/核心覆盖率门禁。

## 已知边界

- 画布覆盖不持久化，也不导出到 PPTX；
- 过渡/动画在 PPTX 中是否保留未验证；
- 母版/主题色板/幻灯片大小未实现；
- 安装包未签名。

## 未验证项（重要）

- **未做 Windows 10/11 干净机安装验收**；
- **Windows 11 未验证**；
- 安装包**未签名**，SmartScreen 会提示未知发布者。
