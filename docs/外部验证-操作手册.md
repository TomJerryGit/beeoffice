# 外部验证操作手册（最后一道门槛）

> 目标：拿到"**外部用户不开 GUI、不用 Python，用 `beecmd.exe` 一条命令完成一件真实工作**"的证据。
> 这是三阶段计划里唯一还需要人来做的一步；工程侧已全部就绪。
>
> **2026-10-20 更新**：本机隔离环境已完成一次（见
> [外部验证-记录-2026-10-20.md](外部验证-记录-2026-10-20.md)）；本手册保留给
> "另一台干净机器"的复核使用。

## 0. 准备

1. 一台 **没装 BeeOffice、没装 Python** 的 Windows 机器；
2. 从 `release-archive/cli/BeeOffice-beecmd-v0.4.0-windows.zip` 解压出 `beecmd.exe`
   （ZIP SHA-256：`aab09dc326f9dfbcdf01db63c494581db1affcd8e64fa4abda145bbb467f8739`）；
3. 一份**可脱敏的真实工作文件**（任选一种）：
   - 2 个 Excel 月报 → 合并成 1 个汇总表；
   - 1 个"脏"表格（空格/空行/重复行）→ 清洗；
   - 1 篇 Markdown 文稿 → 转 `.beshow`；
   - 1 篇文档 + 本地 Ollama → AI 摘要（可选）。

## 1. 先核对 exe（1 分钟）

```powershell
beecmd.exe --version
# 期望：beecmd 0.4.0
```

## 2. 跑一件真实工作并自动留痕（推荐）

用仓库里的采集脚本（`tools/validation_kit.py`，**需要 Python**；目标机器确实没有
Python 时按下文"手工版"记录即可）：

```powershell
# 例：两个月报合并
python validation_kit.py --beecmd beecmd.exe --task merge `
  --input 一月.xlsx --input 二月.xlsx --out-file 汇总.xlsx `
  --out evidence_merge --zip
```

> 如果目标机器确实没有 Python：直接手工运行对应命令，然后记录
> **命令原文、退出码、产物路径、耗时**，回传截图/文本即可；能装 Python 时
> `validation_kit.py` 会自动生成 `evidence.json` + `evidence.md` + `evidence.zip`。

各任务对应命令（手工版）：

| 任务 | 命令 |
|---|---|
| 合并 | `beecmd.exe merge 一月.xlsx 二月.xlsx -o 汇总.xlsx` |
| 清洗 | `beecmd.exe clean 脏表.csv -o 清洗后.xlsx`（有 AI 端点时）或 `--plan 计划.json` |
| 转换 | `beecmd.exe convert 文稿.md --to beshow -o 文稿.beshow` |
| AI 摘要 | `beecmd.exe ai summarize 报告.md --api-base http://127.0.0.1:11434/v1 --model llama3.2 -o 摘要.md` |

## 3. 回传什么

- 命令原文与退出码；
- `汇总.xlsx` / `清洗后.xlsx` / `.beshow` 等**产物**（脱敏后）；
- 若用采集脚本：`evidence.zip`（只含路径/哈希/大小，不含文件内容）；
- 你的机器环境一句话（如 Windows 10 22H2，未装 Python）。

## 4. 判定标准（不改口径）

| 项 | 通过条件 |
|---|---|
| 可运行 | `beecmd.exe --version` 正常输出 |
| 真实工作 | 命令退出码 0，产物存在且能被 Excel/WPS/蜜演打开 |
| 证据 | 命令、退出码、产物哈希（或人工记录）可复核 |
| 独立环境 | 机器确实未装 Python / BeeOffice |

## 5. 已知边界（提前说明，避免误判）

- `md → docx/pdf` 不支持（依赖 Qt 打印引擎，exe 明确排除）；
- exe 未签名，Windows SmartScreen 可能提示"未知发布者"（核对上面的 sha256 即可）；
- AI 任务需要可用的 OpenAI 兼容端点（本地 Ollama 或云端 Key）；
- 20 万行级超大表不做整簿往返（见交付总结 §4）。
