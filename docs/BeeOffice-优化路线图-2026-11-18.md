# BeeOffice 优化路线图（2026-11-18 起）

## 目标

用 6–7 个月把当前“功能齐全的 Beta”推进到 **v6.0 Stable 候选**：

- 文档保真：真实语料往返通过率 ≥95%
- 发布信任：签名 + Win10/11 干净机验收
- 架构收敛：统一领域模型，停止 Mixin 扩散
- 复杂对象：PPT 原生形状/母版/表格，Word 形状/图表
- 稳定性：崩溃率 <0.5% 会话，关键性能有预算

---

## 总原则

1. **冻结新功能面**：P2/边缘功能全部暂停。
2. **先修地基，再做体验**：模型、校验、签名优先于新按钮。
3. **每个阶段有硬门禁**：不达标不进入下一阶段。
4. **单人项目必须取舍**：Word/Excel 优先，PPT/PDF 维持 Beta 至 Q2。
5. **不再发功能型 Beta**：v5.8.14 作为最后一个功能 Beta；之后只发 RC/Stable。

---

## 阶段安排

### Phase 0：止血与立规矩（2026-11-18 → 2026-12-01，2 周）

| 任务 | 产出 |
|---|---|
| 功能冻结 | 变更冻结清单；只修 P0 缺陷 |
| 真实语料库 | 30–50 份 Word/Excel/PPT/PDF 样本 |
| OOXML 校验 | Open XML SDK 校验脚本进入 CI |
| 架构 RFC | 分层规则、领域模型边界、Mixin 冻结令 |
| 发布门禁 | 签名/干净机/测试/SBOM 清单 |
| 证书采购 | 供应商询价与申请材料 |
| v5.8 收尾 | 推送并发布最后 Beta；标注“不再加功能” |

**门禁 G0**：语料库可跑、schema 校验可跑、冻结令生效。

### Phase 1：保真与架构（2026-12 → 2027-02，Q1）

**A. 保真体系**
- Word：节/分栏/页眉页脚/脚注/尾注/TOC/题注/表格/图片
- Excel：公式/样式/条件格式/打印设置/图表基础
- PPT：文本/表格/图片/过渡/基础动画/母版样式
- PDF：批注/页面/转换/水印
- 每类文档建立“导入→编辑→导出→WPS/MS 打开→差异比对”流水线

**B. 架构收敛**
- 建立 `domain / app / adapters / ui` 四层
- 定义三模块统一文档模型 v1
- 新增功能只允许写 domain/app
- 每两周迁移一个 Mixin 到服务层
- 元数据注释升级为版本化 schema

**C. 发布信任准备**
- 证书申请/采购
- 签名脚本接入构建
- 干净机模板（Hyper-V/Packer）

**门禁 G1**：
- 真实语料往返 ≥85%
- schema 校验 100%
- 领域模型 v1 合并
- 签名流程可演示

### Phase 2：复杂对象与信任（2027-03 → 2027-05，Q2）

**A. PPT 原生编辑**
1. 形状：选择框/八向缩放/旋转/层级/组合
2. 母版：标题/正文/图片/日期/页脚占位符绑定
3. 表格：完整行列结构、合并、样式写入 PPTX
4. 图表：多系列/编辑数据/组合图/次坐标轴

**B. Word / Excel 复杂对象**
- Word：文本框、形状、图表、图片环绕
- Excel：图表/透视表就地编辑

**C. 发布信任**
- 签名覆盖 exe/安装器/附带 DLL
- Win10 22H2 + Win11 23H2 干净机自动化
- 非管理员安装/卸载/残留检查
- SmartScreen 验证
- 回滚包与更新通道

**门禁 G2**：
- 签名验证 100%
- 干净机安装成功率 100%
- 复杂对象保存/重开不丢
- 真实语料往返 ≥95%

### Phase 3：稳定化与 v6.0（2027-06 → 2027-07）

- 崩溃/性能/兼容专项
- 20 页 Word、万行 Excel、100 页 PDF、20 页 PPT 性能预算
- 客户模板回归
- 发布说明、迁移指南、支持流程
- v6.0 RC → Stable

**门禁 G3**：
- 全量测试 + 真实验收通过
- 关键指标达标
- 无 P0 缺陷
- 签名与干净机报告齐全

## 风险与应对

| 风险 | 应对 |
|---|---|
| 单人精力不足 | 砍 P2、冻结功能、引入兼职 QA |
| OOXML 注入损坏 | schema 校验 + 真实 Office 打开 + 回滚 |
| 签名证书周期长 | Phase 0 立即申请 |
| 干净机环境不可得 | Hyper-V 自动化模板 |
| 架构重写风险 | 绞杀者模式，禁止大爆炸重写 |
| 兼容性回归 | Golden Corpus + CI 双验收 |
