# 蜜蜂办公 拼写检查技术词白名单
#
# 用途
# ----
# 中文技术文档里大量出现产品名/命令/协议缩写（CentOS、yum、iptables、ens33 …），
# 英文词典不认识它们 → 满屏误报。本文件把这些"词典里没有、但技术语境下正确"的
# 词交给 SpellCheckerService 当成已知词（等价于自动加入自定义词典）。
#
# 规则
# ----
# 1. 一行一个词，**大小写不敏感**（加载时统一小写归一化，见 load_tech_words）。
# 2. ``#`` 开头是注释，空行忽略。
# 3. **只放技术词**：普通英文单词（the / hello / world …）不要放 —— 那些本来就该
#    交给英文词典判断，放进来只会掩盖真正的拼写错误。
# 4. 数字粘连形式（CentOS7 / ens33 / eth0）也要单列，因为它们常被当作独立词查询
#    （见 check_word()）；不过 tokenize_words 本来就会跳过紧贴数字的片段。
# 5. 词表改动不需要改代码；服务默认启动时加载本文件。
