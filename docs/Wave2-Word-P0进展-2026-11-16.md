- `_apply_named_style()`：

  - 标题 1–4：大纲级别 + 字号 + 加粗 + 段前段后；
  - 引用：左右缩进 + 浅灰底纹 + 斜体；
  - 代码：等宽字体 + 浅灰底纹；
- `_clear_formatting()`：清除字符/段落格式；
- 开始页新增“样式库”“清除格式”按钮；
- DOCX 导出测试验证 Heading 样式。
