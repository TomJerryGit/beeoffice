## 2. 总评

**6.5 / 10：工程可信度中上、产品完成度中等、发布成熟度偏低的本地办公套件。**

它已经不是“Demo”，而是有：
- 完整测试/打包/发布链路；
- 真实文档编辑、表格、演示、PDF、分页画布；
- 性能优化和 sha256 更新校验；
- 可用的本地运行包。

但离“可以放心推荐给普通办公用户”的正式产品仍有明显差距：
- 无代码签名；
- 无干净机验收；
- 兼容性证据不足；
- 分页画布仍不是 WPS 级；
- 覆盖率仅 46%。

## 4. 主要发现

### 4.1 优点

- 测试数量可观：1029 项，覆盖核心 UI/文档/导出/安装器；
- 发布包有 sha256 与 `verify_release` 校验；
- 自动更新下载后校验 sha256，仅允许 HTTPS；
- 运行时已移除 PyMuPDF，PDF 后端合规风险下降；
- 分页画布已具备：真实分页、页间间距、页眉页脚、光标、选择、IME、查找、格式联动、表格/图片操作、适合宽度、缩放；
- 性能热点定位准确：`to_markdown` 状态栏调用从每键 25ms 降到基准约 2.3ms。

### 4.2 高风险

1. **安装包未签名**
   - SmartScreen 提示未知发布者；
   - 更新链只有 sha256，没有发布者签名；
   - GitHub 账号或 Release 被篡改时，sha256 不能提供独立信任根。

2. **没有干净机验收**
   - 只在开发机 Windows 10 验证；
   - 未验证首次安装、缺依赖、权限、杀软、升级/回滚；
   - 不能对用户承诺“安装即用”。

3. **兼容性证据不足**
   - 没有完整 Office/WPS 语料回归；
   - Win7 明确不支持（python311.dll）；
   - 真实外部用户为零。

### 4.3 中风险

4. **覆盖率 46%**
   - UI/导出/异常路径覆盖不足；
   - 分页画布大量新代码主要靠少量 Qt 测试。

5. **分页画布仍非 WPS 级**
   - 表格/图片复杂对象仍有连续编辑回退；
   - 页眉页脚/分页与打印一致性未做全量比对；
   - 大文档真实输入仍有 60ms 延迟重排。

6. **高对比度/主题债**
   - 40 文件 / 86 处硬编码 `setStyleSheet`；
   - BeeSheet/BeeShow 仍有未迁移内联样式。

7. **代码集中度**
   - 最大文件 1859 行（beesheet_engine.py）；
   - 多个 1000+ 行 Mixin；
   - 13 个 TODO/FIXME。

### 4.4 低风险/提示

- `eval/exec` AST 命中大多来自 Qt `dialog.exec()` 等合法调用；
- 未发现 `shell=True`、`pickle.loads`；
- 发现两处 `TOKEN` 为模板占位符，不是硬编码凭据；
- 构建脚本有 `os.system`，属于构建工具，不是运行时攻击面；
- 工作区存在打开真实 docx 后生成的 `_media` 与测试文件改动，发布前应清理。

## 5. 优先整改建议

### P0（正式对外前）
1. 代码签名（至少 OV 证书）或明确“未签名测试版”定位；
2. Windows 10/11 干净 VM：安装、启动、卸载、升级、回滚；
3. 兼容性 TOP20 文档 + 导出 PDF/Word 回归；
4. 自动更新端到端：下载、sha256、安装、失败回滚。

### P1
5. 覆盖率从 46% 提升到 ≥60%，优先分页画布/导出/异常路径；
6. 剩余 86 处内联样式迁移；
7. 大文档分页输入延迟继续降到 <10ms；
8. 表格/图片复杂对象与打印/导出一致性测试。

### P2
9. 外部 Beta ≥20 人；
10. 性能/内存长时间稳定性；
11. 依赖许可证清单与第三方声明。

## 6. 最终评价

**BeeOffice v5.4.3 是一个工程上可信、产品上仍有短板的本地办公套件。**

- 适合：技术用户、内部试用、本地隐私优先场景；
- 不适合：普通办公用户无提示部署、企业批量分发、要求 WPS 级排版保真的场景。

**一句话：能跑、能编辑、能发布，但还不能称为“成熟正式版”。**
