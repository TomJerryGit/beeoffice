**这条声明直接决定了对标策略**：  
- "比 WPS 更免费"不构成壁垒（官方已承诺免费不降级）；

## 5. 结论：不能对标的、可低成本追平的、已有优势的

### 5.1 不能 / 不建议对标（结构性放弃）

| 项 | 为什么不能对标 | 证据 |
|---|---|---|
| **云空间 / 网盘** | 机房、带宽、合规、账号体系；WPS 靠 6 亿级用户摊薄，BeeOffice 每多一个用户多一份成本 | [S2][S10]；`docs/WPS对比与深度变革战略.md` §3、§6 |
| **模板 / 素材 / 字体 / 图标生态** | 800 万+ 模板是内容采购与版权运营，不是写代码能追的；且"下载次数"本身就是会员计费点 | [S3][S11] |
| **多人实时协作基础设施** | CRDT/OT + 账号 + 权限 + 存储 + 推送，等于重做一个产品；WPS 与腾讯文档/飞书在打这个战场 | [S14][S12] |
| **PDF 转换 / OCR / 全文翻译 / PDF 版面重排** | 本质是云服务 + 模型 + 排版引擎；质量门槛高、免费替代品多，投入产出比差 | [S1] |
| **在线表单 / 多维表格 / 智能文档 / 思维导图·流程图组件** | 平台级产品矩阵，依赖云与协作底座；WPS 365 打包卖 199 元起 | [S12][S14] |
| **WPS 365 企业平台（含私有化）** | 资质、生态、开放平台、实施服务；BeeOffice 的差异只能是"轻量+可编程+免运维"，不是平台对拼 | [S12][S17]；`docs/WPS对比与深度变革战略.md` §9 |
| **AI 额度 / 点数计费** | 与"本地、透明"定位冲突；WPS 此路线正在引发口碑争议（灵犀 31 天清零、大会员不抵扣） | [S4][S9]；`docs/WPS对比与深度变革战略.md` §1.4 |

### 5.2 可低成本追平（S 级优先，按性价比排序）

| 优先级 | 项 | 成本 | 理由（为什么便宜） |
|---:|---|---|---|
| P0 | **PDF 页面管理：合并 / 拆分 / 提取页面 / 删除页 / 插入页** | **S** | PyMuPDF 已是**必需依赖**（`requirements.txt:59`），`Document.insert_pdf` / `delete_page` 直接可用；做成 `beecmd pdf-merge` / `pdf-split` 还能顺带吃到 CLI 战略 |
| P0 | **PDF 加密/权限**（打开密码、限制打印复制） | **S** | PyMuPDF 保存时支持 encryption/permissions，几十行 |
| P1 | **PDF 水印**（文本/图片水印、页码戳） | **S** | PyMuPDF 文本插入 + 现有蜜写水印逻辑可复用（`README.md:56`） |
| P1 | **PDF 图片签名 / 图章叠加** | **S/M** | 本质是"插入图片 + 坐标"，与批注同源；**法务级电子签不做** |
| P1 | **历史版本时间线（本地）** | **S** | 备份中心 + 草稿已存在（`backup.py`、`drafts.py`），只差一个"按时间列出版本/恢复"的 UI |
| P2 | **PDF 导出图片 / PDF→PNG 序列** | **S** | 与蜜演 PNG 序列导出同构（已有 `beeshow` PNG 导出） |
| P2 | **文档瘦身 / 繁简转换 / 长图片** | **S/M** | 繁简可查表；长图片复用现有渲染/导出链路；瘦身可做"删除未用媒体+压缩图片" |
| P3 | **中文拼写 / 校对** | **M/L** | 已有拼写后端框架与白名单机制（`spellcheck.py`），但中文需要分词/词典，M 起步 |

> 结论：**WPS 会员里唯一"工程可追平"的大类就是 PDF 的页面级 + 权限级工具**（不含转换/OCR/翻译）。这几项占会员卖点里的高频提及（[S1][S10]），但实现成本对 BeeOffice 是 S 级——因为它已经有 PyMuPDF 和批注/烧录链路。

### 5.3 已有对齐 / 反超（应当作为对外卖点，而不是继续加功能）
