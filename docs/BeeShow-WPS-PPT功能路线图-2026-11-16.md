# BeeShow 参考 WPS PPT 功能优化路线图

日期：2026-11-16  
基线：BeeOffice v5.4.7 Beta  
范围：BeeShow（演示文稿）

## 1. 目标与原则

参考 WPS 演示的页签和功能组织，不复制品牌素材：

1. 页签对齐：开始 / 插入 / 设计 / 切换 / 动画 / 放映 / 审阅 / 视图 / 工具 / AI；
2. 先发挥 BeeShow 现有的 Markdown/HTML 内容优势；
3. 再补 WYSIWYG 画布编辑，不先追求完整复刻 WPS；
4. 所有新对象必须可选中、缩放、撤销、导出 PPTX；
5. 演示交付（放映/演讲者/排练/导出）优先于装饰功能。

## 4. 路线图

### P0：演示核心闭环（3–4 周）

| 任务 | 验收标准 |
|---|---|
| 幻灯片管理面板 | 缩略图、拖拽排序、复制/删除/隐藏 |
| 新建/版式 | 新建空白/标题/内容页；版式选择 |
| 设计基础 | 主题、背景、配色、统一字体 |
| 过渡面板 | 效果库、速度、应用到全部、预览 |
| 动画面板 | 动画库、顺序、时长、删除 |
| 放映闭环 | 从头/当前、演讲者视图、备注、排练 |
| 画布编辑基础 | 文本框/图片选中、移动、缩放、删除、撤销 |
| 导出测试 | PPTX/PDF/HTML/图片往返 |

## 5. 技术前置

1. **幻灯片对象模型**：页面、元素、层级、位置/尺寸、样式统一抽象；
2. **WYSIWYG 画布**：元素选中、拖拽、缩放、对齐、撤销；
3. **母版/版式**：主题、占位符、统一字体/颜色；
4. **过渡/动画**：可视化配置与导出兼容；
5. **PPTX 往返**：元素/图片/表格/动画不丢；
6. **渲染性能**：大图/多页缩略图懒加载；
7. **测试**：20 页带图/表/动画的导出与重新导入。

## 6. 建议执行顺序

```text
第 1 周：幻灯片管理面板 + 新建/版式
第 2 周：设计基础 + 过渡/动画面板
第 3 周：画布编辑基础（文本/图片）
第 4 周：放映闭环 + 导出回归 + Beta
第 5–8 周：形状/表格/图表/母版/视图
第 9 周起：审阅增强/AI 生成/专业工具
```

## 7. 不承诺项

- 不完整复刻 WPS 全部动画/模板/素材库；
- 不复制 WPS 品牌图标和模板；
- 不在画布对象模型稳定前堆形状/图表；
- 宏/云协作/实时字幕需单独立项。

## 8. 结论

BeeShow 的强项是 Markdown/HTML 内容生产、AI 大纲、主题、导出和放映；短板是 WPS 那种**所见即所得画布编辑**和**幻灯片管理**。

优先补：

```text
幻灯片管理 → 设计/过渡/动画 → 画布编辑 → 放映/导出闭环 → 形状图表 → AI/专业工具
```

先把“做一页、改一页、放一页、导一份”跑顺，再谈完整 WPS 复刻。
