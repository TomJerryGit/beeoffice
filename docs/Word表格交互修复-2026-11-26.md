# Word 表格交互修复

日期：2026-11-26

## 问题

- 插入 Word 表格后无法点击编辑；
- 无法拉伸/收缩表格或列宽。

## 修复

- 富文本编辑器显式 `setReadOnly(False)` 与 `TextEditorInteraction`；
- 列边界鼠标拖拽调整列宽；
- 表格属性新增：
  - 列宽（cm，逗号分隔）
  - 表格宽度
  - 按表格宽度等分列宽
- 保留原有对齐/边框/内边距/背景色。

## 验证

```text
test_table_cell_is_editable
test_table_column_drag_resize
全量：1713 passed
```

## 边界

- 目前拖拽只调整列宽，不直接拖动整表位置；
- 行高拖拽未做；
- 复杂合并单元格的列宽拖拽可能受跨度影响。
