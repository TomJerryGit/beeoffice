# BeeOffice v5.5.0

发布日期：2026-11-16  
Release：https://github.com/TomJerryGit/beeoffice/releases/tag/v5.5.0  
发布状态：**Beta / Unsigned**（未签名；未做干净机验收；Win11 未验证）

## 重点更新（Wave 2：Word P0）

### W5 样式/段落
- 样式库：正文/标题 1–4/引用/代码；
- 清除格式；
- 样式导出 DOCX 保留 Heading 1–4；
- 段落格式对话框此前已有。

### W6 页面/页眉页脚
- 页面设置新增分栏（1–4）与行号开关；
- 页眉页脚设置：首页不同、奇偶页不同、首页/偶数页页眉页脚；
- DOCX 导出写入 first_page/even_page 页眉页脚；
- 分栏导出写入 HTML `column-count`。

### W7 注释/题注/目录
- 脚注/尾注：上标编号 + 内存记录；
- 题注（图/表/公式）与交叉引用；
- 目录更新（按标题重建）；
- 字数统计对话框；
- 接受/拒绝修订沿用已有修订管理器。

### W8 视图/导出收尾
- 全屏、标尺、网格、单页/多页入口；
- 脚注/尾注 DOCX 导出为文末注释区；
- 20 段 DOCX 导出性能基线与测试。

### 工程化
- 全量测试 **1598 passed**；
- 安全扫描高危 0；
- 依赖锁与 CycloneDX SBOM 保持；
- CI 全量测试/安全扫描/核心覆盖率门禁。

## 已知边界（Word P0）

- 脚注/尾注不是 Word 原生脚注，只写文末注释区；
- 题注/交叉引用是文本，不是 Word 域；
- 目录是纯文本目录，不是 Word TOC 域；
- 分栏/行号只在导出 HTML 中应用，DOCX 未完全写入；
- 打印缩放/按页页眉页脚仍待后续。

## 未验证项（重要）

- **未做 Windows 10/11 干净机安装验收**；
- **Windows 11 未验证**；
- 安装包**未签名**，SmartScreen 会提示未知发布者。
