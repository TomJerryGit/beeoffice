# BeeOffice v5.4.8

发布日期：2026-11-16  
Release：https://github.com/TomJerryGit/beeoffice/releases/tag/v5.4.8  
发布状态：**Beta / Unsigned**（未签名；未做干净机验收；Win11 未验证）

## 重点更新（Wave 1：Excel P0）

### 页面/打印
- 新增“页面”页签：打印预览、页面设置、设置/取消打印区域；
- 页边距、纸张方向、纸张大小、页眉/页脚文字；
- 打印区域只输出选中范围；
- 分页预览入口复用打印预览。

### 审阅
- 新增“审阅”页签：保护工作表/工作簿、插入/查看批注、拼写检查。

### 公式
- 函数分类菜单；
- 显示公式；
- 错误检查；
- 计算选项（自动/手动/立即重算）。

### 数据工具
- 删除重复项；
- 分列；
- 分类汇总（结果预览）；
- 合并计算（结果预览）。

### 视图/网格
- 网格线、行号列标、显示比例、页面布局开关；
- 网格行按滚动按需扩展，取消 5000 行硬上限；
- XLSX 数据级往返测试。

### 工程化
- 全量测试 **1585 passed**；
- 安全扫描高危 0；
- 依赖锁与 CycloneDX SBOM 保持；
- CI 全量测试/安全扫描/核心覆盖率门禁。

## 已知边界

- 打印缩放设置已保存，但渲染尚未真正应用；
- 页眉/页脚当前只在文档首尾，尚未按页重复；
- 分类汇总/合并计算为结果预览，不直接插入原表；
- 数据验证“文本长度”类型未落地；
- 拼写检查为基础常见错误词典。

## 未验证项（重要）

- **未做 Windows 10/11 干净机安装验收**；
- **Windows 11 未验证**；
- 安装包**未签名**，SmartScreen 会提示未知发布者。
