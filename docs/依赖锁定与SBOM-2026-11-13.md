# 依赖锁定与 SBOM（M2 第一项）

日期：2026-11-13  
版本：v5.4.7（开发中）

## 1. 锁文件

新增两个 `pip-compile` 生成的锁文件（含 SHA-256 hashes，Windows / Python 3.11）：

| 文件 | 输入 | 用途 |
|---|---|---|
| `requirements.lock` | `requirements.txt` | 运行时/打包依赖 |
| `requirements-dev.lock` | `requirements-dev.txt` | 测试/静态检查/打包工具 |

安装：

```powershell
python -m pip install --require-hashes -r requirements-dev.lock
```

CI 的 `全量测试` 和 `windows-release` 已改用 `requirements-dev.lock`。

重新生成：

```powershell
# 必须在仓库外执行，避免本地 build.py 遮蔽 build 包
cd $env:TEMP
python -m piptools compile `
  "D:\beeofficeV\_ptmp\s4\requirements-dev.txt" `
  --output-file "D:\beeofficeV\_ptmp\s4\requirements-dev.lock" `
  --generate-hashes --allow-unsafe --resolver=backtracking

python -m piptools compile `
  "D:\beeofficeV\_ptmp\s4\requirements.txt" `
  --output-file "D:\beeofficeV\_ptmp\s4\requirements.lock" `
  --generate-hashes --allow-unsafe --resolver=backtracking
```

> 生成后需去掉锁文件注释里的绝对路径（或使用本仓库已处理版本）。

## 2. SBOM

已生成：

```text
sbom/cyclonedx-bom.json
```

- 格式：CycloneDX JSON
- 主组件：`BeeOffice`，版本跟随 `beeoffice/__version__.py`
- 依赖来源：`requirements.lock`
- 生成时使用 `--output-reproducible`，避免时间/随机值

生成命令：

```powershell
python -m cyclonedx_py requirements requirements.lock `
  --of json -o sbom/cyclonedx-bom.json --output-reproducible
```

release workflow 已把 `sbom/cyclonedx-bom.json` 加入上传产物。
