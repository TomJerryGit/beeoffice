## 2. 主要问题

### UI-01 快捷键覆盖不足
- 文件/新建/保存/打开等核心动作有快捷键；
- 但导出、模板、云同步、PDF、宏、批量等 51 个叶子菜单项无快捷键；
- 需要区分“应该给快捷键”的高频动作与“不需要”的低频动作。

### UI-02 图标按钮缺少可访问名称
- 2 个可见 QToolButton 没有 `accessibleName`，也没有可读文本；
- Ribbon 中相当一部分按钮依赖 tooltip/图标，屏幕阅读器无法识别；
- 需要为图标按钮统一补 `accessibleName` 和 `toolTip`。

### UI-03 键盘导航未验证
- 当前审计只盘点菜单/控件，未验证 Tab 顺序、焦点可见性、对话框 Esc/Enter；
- 核心流程（新建 → 编辑 → 保存 → 导出 → 关闭）尚未做纯键盘验收。

### UI-04 视觉回归未建立
- 尚无关键页面截图基线；
- 100% / 150% / 200% DPI 与中英文布局未截图对比。
