## 1. 复现命令（照抄可跑）

```powershell
cd D:\beeofficeV
$env:QT_QPA_PLATFORM = 'offscreen'      # 无头跑 Qt 测试
$env:PYTHONPATH      = 'D:\beeofficeV'

# ① 全量保真 + 单元测试（约 4 分钟）
python -m pytest tests/fidelity tests/unit -q -p no:cacheprovider -o log_file= --timeout=1500

# ② 33 项门禁（确定性项阻断失败；计时项只报告）
python tools\check_gates.py

# ③ 静态检查（阻断子集 = 未定义名/重复定义/语法）
python -m ruff check beeoffice tests tools --select F821,F811,E9
#    未用导入清零（新增即失败）
python -m ruff check beeoffice tests tools --select F401,TC005

# ④ 语法总检（**只读**，不写 __pycache__；实测输出：语法检查文件数: 134）
#    ⚠️ 不要用 `python -m compileall`：它要写 __pycache__，会被沙箱拒绝
#    （我第一版把它写进文档，实测复跑才发现跑不通 —— 文档里的命令必须自己先跑一遍）
python -c "import ast,pathlib; files=list(pathlib.Path('beeoffice').rglob('*.py')); [ast.parse(p.read_text(encoding='utf-8')) for p in files]; print('语法检查文件数:', len(files))"

# ⑤ 整套隔离跑（含 QtWebEngine 用例时更稳，逐文件子进程）
python tools\run_tests_isolated.py --quiet

# ⑥ Office 产出物结构校验（用 DSH 自带 office 技能里的检查器）
<bundled-python> <office-skills>\scripts\check_office.py <产出文件.xlsx> --out checks.json
```

**环境限制（会影响结果，先看这里）**

* **QtWebEngine 在本机无法初始化**（`platform_channel.cc` FATAL）→
  涉及"蜜演"实例化的用例只能做**类级**断言；相关回归文件在整套跑时会挂，故用 ⑤ 隔离跑。
* **本机没有 xlwt / LibreOffice** → 造不出真实 `.xls` 夹具，`.xls` 读取按"引擎选择 + 接线"验证。
* **程序无法写仓库源文件**（沙箱限制，`os error 5`）→
  `ruff --fix` 需要一次性放宽权限（第 11 批已说明并留记录）。

## 6. 过程教训（团队可直接复用的六条）

1. **先验仪器，再看结论**：本轮多次"看起来达标"其实是坏仪器——
   比如统计行数用 `Get-Content .Count` 得到 691 而真实 1024；复现脚本加归一化却没把修复写回模块。
2. **写/读成对的逻辑必须测"互逆"**：`parse(format(x)) == x` 一条属性测试，
   抓到了"货币格式读回静默丢失"这类只测正向就全绿的 bug。
3. **自动修复要审副作用**：`ruff --fix` 删掉了冒烟测试的**兼容契约**、留下空块——
   大范围自动改动后必须**人工审 diff** + 全量回归。
4. **测试要能"有牙"**：裸控件测不出快捷键冲突（没有菜单就没有冲突）；
   常量桩测不出"全部替换"的偏移错误（用会变的文本 + 不等长替换词才行）。
5. **数据优先于外观**：写格式遇合并区先保数据（跳过合并并计数）；
   绝不在 `.xls` 上原地写（能读不能写就明说）。
6. **失败要能说出来**：`_generate_chart` 缺库静默返回、`_analyze_data` 点不动、
   `_save_current` 分支不命中——"什么都不发生"是最糟的失败模式，全部改为明确提示。
