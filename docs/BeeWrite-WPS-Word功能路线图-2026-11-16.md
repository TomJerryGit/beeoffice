# BeeWrite 参考 WPS Word 功能优化路线图

日期：2026-11-16  
基线：BeeOffice v5.4.7 Beta  
范围：BeeWrite（Word 文档）功能与 Ribbon 体验

## 1. 目标与原则

目标不是复制 WPS 品牌素材，而是参考其**信息架构和功能完整度**：

1. 保留 WPS 式页签：开始 / 插入 / 页面 / 引用 / 审阅 / 视图；
2. 增加 BeeOffice 自己的「工具 / AI / 模板」入口；
3. 先补“写文档真正会用”的功能，再补锦上添花；
4. 每个功能必须 DOCX 往返不丢、可撤销、可测试；
5. 不引入与本地优先冲突的强制云服务。

## 4. 路线图

### P0：核心写作可用性（2–3 周）

| 任务 | 验收标准 |
|---|---|
| 样式库面板 | 标题 1–6/正文/引用/代码样式一键套用；DOCX 往返保留 |
| 段落格式对话框 | 行距/段前/段后/首行缩进/边框/底纹 |
| 清除格式 | 清除选中文字/段落格式 |
| 页面设置补全 | 页边距/纸张方向/纸张大小/分栏/行号 |
| 页眉页脚与页码 | 首页不同/奇偶页不同；页码格式 |
| 脚注/尾注 | 插入/编号/跳转；DOCX 导入导出 |
| 题注/交叉引用 | 图表题注、引用更新 |
| 目录更新 | 标题变化后更新目录/页码 |
| 审阅闭环 | 接受/拒绝修订、字数统计 |
| 视图快捷项 | 全屏、标尺、网格线、单页/多页 |
| 写作文档测试 | 20 页带图/表/目录/页眉页脚文档往返 |

### P1：WPS 办公常用能力（3–5 周）

| 任务 | 验收标准 |
|---|---|
| 封面/空白页/文档部件 | 可插入、可删除、分页正确 |
| 形状/艺术字/截图 | 插入、缩放、旋转、删除、撤销 |
| 图表/流程图/思维导图 | 至少支持嵌入静态图形 + 可编辑占位 |
| 页面边框/背景/稿纸 | 页面级样式，打印/导出正确 |
| 书签/索引/邮件合并 | 基础可用 |
| 文档比较/合并 | 差异高亮、接受/拒绝 |
| 限制编辑/加密/定稿 | 密码保护、只读、最终版标记 |
| 翻译/简繁/朗读 | 可选 AI/系统能力，失败可降级 |
| 视图增强 | Web 版式、护眼、重排窗口 |

### P2：AI 与专业场景（按需）

| 任务 | 说明 |
|---|---|
| 选中改写/扩写/缩写 | 基于选区，不整篇替换 |
| AI 校对/排版 | 可撤销、可逐条接受 |
| 文档问答/全文总结 | 需明确隐私边界 |
| 论文助手 | 目录/引用/参考文献/查重接口需单独评估 |
| 宏/开发工具 | 与插件系统统一，注意安全 |

## 5. 技术前置

这些能力不应直接堆 UI，先补底层：

1. **文档对象模型**：段落/样式/页面/脚注/题注统一抽象；
2. **分页引擎**：页眉页脚、分页符、分节、页码稳定；
3. **DOCX 往返**：导入→编辑→导出不丢样式；
4. **图形对象层**：形状/图片/图表统一选中、缩放、撤销；
5. **撤销/重做**：所有新功能必须可撤销；
6. **测试**：每个功能做 DOCX 回读测试，不只截图验收。

## 6. 建议执行顺序

```text
第 1 周：样式库 + 段落格式 + 清除格式
第 2 周：页面设置 + 页眉页脚/页码 + 脚注尾注
第 3 周：题注/交叉引用/目录更新 + 审阅闭环
第 4 周：视图增强 + 发布 Word 专项 Beta
第 5–8 周：封面/形状/图表/页面装饰
第 9 周起：AI 改写/校对/文档问答
```

## 7. 不承诺项

- 不追求完整复刻 WPS 全部 200+ 命令；
- 不复制 WPS 品牌图标/素材；
- 不在没有 DOCX 往返保障时上线复杂排版功能；
- 论文助手/宏/云文档等专业能力需单独立项。

## 8. 结论

BeeWrite 已经有可用的 Ribbon、AI 和基础 DOCX 能力，但离 WPS Word 的“写作闭环”还差：

```text
样式 → 分页 → 页眉页脚 → 脚注/题注 → 目录 → 审阅 → 导出
```

优先补 P0 的这条主链，比继续增加按钮更重要。
