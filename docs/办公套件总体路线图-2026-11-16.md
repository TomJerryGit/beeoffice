# BeeOffice 办公套件总体路线图（参考 WPS）

日期：2026-11-16  
基线：BeeOffice v5.4.7 Beta  
参考：[BeeWrite Word](BeeWrite-WPS-Word功能路线图-2026-11-16.md)、[BeeSheet Excel](BeeSheet-WPS-Excel功能路线图-2026-11-16.md)、[BeePDF PDF](BeePDF-WPS-PDF功能路线图-2026-11-16.md)、[BeeShow PPT](BeeShow-WPS-PPT功能路线图-2026-11-16.md)

## 1. 总体判断

四个模块的共性问题不是“按钮不够”，而是**核心工作流不完整**：

```text
Word：样式 → 分页 → 页眉页脚 → 脚注/目录 → 审阅 → DOCX 导出
Excel：页面/打印 → 公式 → 数据工具 → 保护 → 视图 → XLSX 导出
PDF：页面缩略图 → 批注 → 保护 → 转换
PPT：幻灯片管理 → 设计/切换/动画 → 画布编辑 → 放映/导出
```

因此总体路线不按“同时铺开四个模块”安排，而按：

```text
共享底座 → Excel P0 → Word P0 → PDF P0 → PPT P0
→ 四个模块 P1 → AI/专业 P2
```

原因：

- 一个人 + AI 助手，并行四条深改会互相冲突；
- Excel/Word 的 P0 依赖最少、用户最高频；
- PDF 后端已较完整，主要补 UI/页面工作流；
- PPT 的画布/母版改造最大，放最后单独攻坚；
- 共享 Ribbon、图标、隐藏主菜单已基本完成。

## 2. 全模块优先级总表

| 优先级 | Word | Excel | PDF | PPT |
|---|---|---|---|---|
| **P0 核心闭环** | 样式/分页/页眉页脚/脚注题注/目录/修订 | 页面打印/公式/数据工具/保护/视图/网格 | 页面缩略图/批注增强/保护/转换基础 | 幻灯片管理/设计/过渡动画/画布基础/放映导出 |
| **P1 办公常用** | 封面/形状/图表/页面装饰/比较/加密 | 图表/透视表/条件格式管理器/AI | 插入/页面加工/对比/证书签名/OCR/Office 转换 | 形状/图表/母版/视图/审阅/AI 生成 |
| **P2 专业场景** | 论文助手/宏 | 获取数据/股票/宏 | 表单/发票/电子签/CAD | 录屏/遥控/宏/云协作 |

## 3. 共享底座

P0 每个模块都依赖以下能力，应优先一次做稳：

1. **Ribbon 框架**：已完成页签/组/图标/主题/隐藏主菜单；
2. **撤销/重做**：新功能必须可撤销；
3. **文档往返**：DOCX / XLSX / PPTX 导入导出不丢；
4. **打印/导出框架**：页面布局、分页、页眉页脚、PDF 导出；
5. **对象模型**：Word 段落/样式、Excel 网格/图表、PPT 页面/元素；
6. **性能基线**：Word 20 页、Excel 1 万行、PDF 100 页、PPT 20 页；
7. **测试基线**：每个功能有回读测试，不只截图。

> 共享底座不单独占一个大版本，穿插在每个 Wave 的前半周完成。

## 6. 时间与资源

按“1 名开发者 + AI 助手”估算：

```text
四模块 P0：约 16 周
四模块 P1：约 8–10 周
共享底座/回归/发布：额外 3–4 周
```

不建议并行推进 Word + Excel + PDF + PPT 四个深改；  
每进入下一 Wave 前，必须完成上一 Wave 的：

- 全量测试；
- 往返回读；
- 发布前冒烟；
- Release Notes；
- 用户可感知的验收。

## 7. 风险

| 风险 | 处理 |
|---|---|
| PPT 画布编辑工作量被低估 | 单独 Wave，先对象模型 |
| PDF 任意文字编辑不现实 | 明确只做页面/批注/转换 |
| Word 分页/目录 复杂度高 | 先稳定 20 页文档 |
| Excel 百万行性能 | 虚拟网格，不预分配 |
| 无签名/无干净机 | 继续 Beta，不冒充 Stable |
| AI/云能力依赖外部服务 | 可选、可降级、隐私说明 |

## 8. 验收指标

```text
Word：20 页 DOCX 往返；样式/目录/页眉页脚不丢
Excel：1 万行打开/排序/筛选；xlsx 打印设置不丢
PDF：100 页翻页；批注保存/烧录；页面操作不破坏原文件
PPT：20 页 PPTX 往返；放映/演讲者/导出可用
```

## 10. 结论

总路线不是“四个模块同时追 WPS”，而是：

```text
共享底座 → Excel P0 → Word P0 → PDF P0 → PPT P0
→ P1 按频率滚动 → P2 专业能力
```

**先让每个模块具备完整工作流，再谈功能数量。**  
当前最值得投入的是 Excel 页面/打印、Word 样式/分页、PDF 页面缩略图、PPT 幻灯片管理。
