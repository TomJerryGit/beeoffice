## 三个真实动态求值点

### 1. `beeoffice/plugins/formula_engine.py:378` — 旧公式引擎 eval

```python
result = eval(expr_with_values, {"__builtins__": {}}, allowed_names)
```

- 输入来源：旧 `FormulaEngine` 实例的 `expr` 参数，即公式字符串。
- 生产可达性：**当前不可达**。全仓引用仅出现在：
  - `tests/unit/test_formula_engine.py`
  - `tests/unit/test_core_100_batch3.py`
  - `tests/smoke/test_smoke_imports.py`
  - `tools/check_imports.py`
  - 自身 docstring
- 已验证风险：`=().__class__.__bases__[0].__name__` 可正常返回 `object`，说明 **属性访问和下标访问未被禁止**。这是典型的 `eval` 沙箱逃逸前置条件。
- 定级：**P1 潜在 RCE（当前不可达）**。
- 处理建议：删除旧引擎，或把 `_eval_math` 改为与 `beesheet_engine._safe_eval` 相同的 AST 白名单；在修复前不要把该模块暴露给插件/UI。

### 2. `beeoffice/plugins/beesheet_engine.py:723` — 蜜算安全求值

```python
tree = ast.parse(expr_with_values, mode="eval")
# 白名单：Expression/BoolOp/BinOp/Compare/Constant/Name/Tuple/List/Call
# 调用白名单：abs, round, int, float, min, max

```

- 输入来源：用户单元格公式、粘贴内容、导入表格中的公式文本。
- 安全措施：AST 白名单拒绝 `Attribute`、`Subscript`、`Lambda`、推导式、Import 等；调用仅允许 6 个安全函数；`__builtins__` 为空。
- 定级：**P3 低风险（已加固）**。
- 建议：保留现有 P0 回归用例，并补充“属性/下标/惰性调用”攻击样例作为回归测试。

### 3. `beeoffice/build_release.py:28` — 构建脚本 exec

```python
content = version_file.read_text(encoding="utf-8")
exec(content, namespace)
```

- 输入来源：仓库内的 `beeoffice/__version__.py`，由开发者/构建环境控制。
- 影响面：构建机，不是终端用户输入；但如果仓库内容被篡改，构建机可执行任意代码。
- 定级：**P3 构建期风险**。
- 建议：改为正则读取 `__version__ = "x.y.z"`，或用 `ast.literal_eval` 解析常量，不使用 `exec`。

## 89 处 Qt `.exec()` 为什么不是高危

这些是：

```python
dialog.exec()      # QDialog 模态事件循环
menu.exec(pos)     # QMenu 弹出
app.exec()         # Qt 主事件循环
```

输入来源是本地鼠标/键盘事件和 Qt 控件状态，不是 Python 代码字符串，**不会执行任意代码**。  
扫描规则应排除 `\.exec\s*\(`，或只匹配裸 `exec(` / `exec (`。
