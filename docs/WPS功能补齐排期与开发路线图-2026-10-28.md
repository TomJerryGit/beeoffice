## 1. 优先级规则

1. **P0 先做“数据已在、只差入口/写回”的项**：冻结窗格、多级排序、数字格式、条件格式/数据验证写回、页眉页脚/页码/目录；
2. **P0 再做“WPS 对标最快”的插件**：PDF 工具箱 GUI（复用 beecmd）、AI 任务窗格、本地模板中心；
3. **P1 做“专业度”**：演示母版/动画窗格、图片环绕/裁剪、形状、数据工具箱、校对；
4. **P2 只做能形成差异化的**：宏/脚本、投屏、PDF 签名/书签、思维导图；
5. **明确不做**：云文档/实时协作、模板内容运营、PDF 转换/OCR/翻译全家桶、企业 365、原生多端。

## 5. 风险与缓冲

| 风险 | 概率 | 影响 | 缓冲 |
|---|---|---|---|
| Writer tracked changes/域体系比预估复杂 | 中 | S1/S2 延期 | 先做“静态可更新目录/页码/题注”，tracked changes 延后 |
| PPTX 母版/动画受引擎限制 | 中 | 演示专业度不达标 | v5.2 先做“导出可用”，高保真导入列 P2 |
| 插件 API 安全/兼容 | 中 | 生态不可信 | 权限白名单 + 子进程隔离 + 契约测试 |
| 宏控制台被滥用 | 中 | 安全风险 | 默认禁用 + 白名单命令 + 审计 |
| 性能回退 | 中 | 口碑 | 每 Sprint 跑基准；P95 门禁 |
| 远端 main 分叉冲突 | 高 | 合并延期 | 提前 W1 审计、独立集成分支、分批 port |
| CI runner 环境漂移 | 低 | 发布阻塞 | 已固化 cmd/干净 worktree/日志；每日检查 |

## 7. 不排期项（明确不做/延后）

| 项 | 原因 |
|---|---|
| 云文档/多人实时协作 | 服务端/网络效应/合规成本 |
| 模板/素材内容运营 | 内容运营重资产；只做本地模板包 |
| PDF 版面编辑/PDF↔Office 转换/OCR/翻译 | 重引擎/合规/准确率风险 |
| 企业 365/管理后台 | 产品定位不匹配 |
| 原生多端（Mac/Linux/手机编辑） | 先 Windows + 浏览器只读 |
| 动态数组/原生图表/SmartArt | 引擎级重写，列 P2 长期 |
| 视频导出 | 需 ffmpeg/编码链，列插件延后 |
