# PPT 母版/占位符保留进展

日期：2026-11-19

## 已实现

- 提取每页版式名称；
- 提取母版/版式/页面背景色；
- 提取占位符类型与几何信息（left/top/width/height）；
- 导出时恢复每页背景色。

## 完整母版/版式 XML 保留

导出时若存在源 PPTX：

1. 打开源文件作为 Presentation 基底；
2. 删除源全部幻灯片；
3. 保留 master/layout/theme 部件；
4. 按源页 layout 名称选择版式；
5. 在源版式上生成新页。

验证：

```text
导出页 slide_layout.name == 源页 layout.name
```

## .beshow 持久化源母版路径

保存 `.beshow` 时写入：

```text
<!-- beeshow-pptx-source:{"path":"...pptx"} -->
```

打开时：

- 恢复 `_pptx_source_path`；
- 重新提取母版背景/版式/占位符元数据；
- 源文件不存在时降级，不影响打开。

## 占位符重建

导出时：

1. 按源占位符文本寻找导出页中的同文本形状；
2. 移除重复文本形状；
3. 在源占位符几何位置创建近似占位符形状；
4. 写入 `p:ph` 类型与 idx。
