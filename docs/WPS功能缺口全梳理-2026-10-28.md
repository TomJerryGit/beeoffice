# WPS 有、BeeOffice 没有的功能全梳理（2026-10-28）

> 目标：把 WPS 的**常用功能**、**提升型/专业化功能**、**UI/生态型功能**中 BeeOffice 仍缺失或只做了一半的部分，一次性梳理清楚，并给出“核心修复 / 做成插件 / 明确不做”的处置建议。
>
> 证据边界：
> - WPS 侧来自公开官网/帮助/开放平台（见文末来源），**未登录 WPS、未做同机盲测**；
> - BeeOffice 侧以 v5.0.29 代码/测试/截图为准；
> - 既有 294 行细节矩阵：[WPS功能细节深度对标与首批提升-2026-10-22.md](WPS功能细节深度对标与首批提升-2026-10-22.md)；
>   矩阵中 132 行“缺失/部分”是本文基础，但**已按 v5.0.29 修正**（见 §0.2）。
>
> 状态：❌ 缺失；🟡 部分/入口缺失；✅ 已对齐；⭐ BeeOffice 差异化反超。
> 优先级：P0 = 高频刚需；P1 = 明显提升体验/竞争力；P2 = 专业化或低频率；不做 = 结构性放弃。

## 0. 先给结论

### 0.1 一句话

BeeOffice 缺的不是“再补几个按钮”，而是四类东西：

1. **文档版式深水区**（页眉页脚/页码/目录域/题注/重复表头/图片环绕）；
2. **表格专业计算**（动态数组、原生图表、条件格式/数据验证完整写回、多级排序、冻结窗格）；
3. **演示专业结构**（母版、动画窗格、形状/图表、视频导出）；
4. **WPS 生态型能力**（PDF GUI、AI 任务窗格、模板中心、云协作、移动端、宏/加载项）。

### 0.2 对旧矩阵的两处重要修正

- **PDF 基础工具已不再“缺失”**：beecmd v0.5.0 已提供 `pdf-merge / split / extract / delete / encrypt / watermark / text / images`（CLI）。
  现在缺的是 **GUI、页面旋转/裁剪/插入替换、签名/图章/书签、压缩**，以及 PDF 编辑/转换/OCR（后者明确不做）。
- **UI 已补**：Ribbon 标签/分组/多行/折叠、文件入口、快速访问栏、统一图标、主题、蜜算/蜜写“表格工具”上下文标签已在 v5.0.29 落地。
  现在缺的是 **Backstage 文件页、任务窗格、图片/图表上下文标签、命令搜索、模板启动中心、动画面板**。

### 0.3 数量概览（按本文清单，非严格去重计数）

| 大类 | 缺失/部分项 | 其中高频 P0/P1 | 主要处置 |
|---|---:|---:|---|

| 7 | 版本历史（云端） | 本地备份/草稿 | 🟡 | 可做本地版本历史 |
| 8 | 企业 365/私有化/管理后台 | 无 | ❌ | 不做平台 |
| 9 | 移动端/平板/多端 | 只读浏览器 | ❌ | 不做原生多端 |
| 10 | 模板/素材/字体内容运营 | 无 | ❌ | 只做本地模板包 |

## 8. 处置：核心修复 vs 插件化

### 8.1 应做核心修复（不适合插件）

这些需要深度改编辑器/文档模型，插件 API 做不稳：

1. 页眉页脚编辑 UI + 首页/奇偶/分节；
2. 页码体系（格式/起始/分节）；
3. 目录更新域、题注/图表目录；
4. 表格跨页重复标题行；
5. 图片环绕/裁剪、形状库；
6. 冻结窗格 UI、多级排序、条件格式公式/图标写回、数据验证类型、数字格式、边框填充写回；
7. 原生图表对象/组合图（重）；
8. 演示母版/动画窗格/形状/图表；
9. 文档保护/加密/限制编辑；
10. 修订 tracked changes（重）。

### 8.2 最适合做成插件（按 ROI）

| 优先级 | 插件 | 覆盖的 WPS 能力 | 价值/成本 | 说明 |
|---|---|---|---|---|
| **1** | **AI 文档助手** | 文档问答、改写、翻译、表格洞察、PDF 摘要 | 5/3 | 任务窗格 + RAG + 现有 AI Provider |
| **2** | **PDF 工具箱 GUI** | 合并/拆分/加密/水印/提取/压缩/签章/书签 | 4/2 | 复用 beecmd v0.5.0，最快可交付 |
| **3** | **本地模板/素材中心** | 模板库、启动中心、示例 | 5/3 | 只做本地包，不做云内容 |
| **4** | **数据工具箱** | 多级排序、透视刷新、图表推荐、清洗、智能填充 | 4/3 | 蜜算命令 API + UI |
| **5** | **演示美化/动画库** | 版式/主题/切换/动画/一键美化 | 4/4 | 依赖母版/动画能力 |
| **6** | **校对与格式体检** | 拼写/语法/样式/一致性/无障碍 | 4/2 | 现有 spellcheck + 规则 |
| **7** | **宏/脚本控制台** | JS 宏/VBA 替代 | 4/4 | 需插件 API + 沙箱 |
| **8** | **投屏/手机遥控** | 手机遥控/在线演示 | 3/2 | 复用 beeshow_sync_server |
| **9** | **思维导图/流程图** | 脑图/流程图 | 3/4 | 独立编辑器插件 |
| **10** | **OCR/文档转换** | PDF OCR/转换 | 2/5 | 建议第三方引擎接入，不做自研 |

### 8.3 明确不做

- 云文档/网盘/多人实时协作；
- 企业 365/管理后台/私有化平台；
- 模板/素材/字体内容运营（只做本地包格式）；
- PDF 版面编辑、PDF↔Office 转换、OCR/翻译全家桶（可第三方接入）；
- 在线表单/多维表格/SmartArt 深度实现；
- 原生多端（Windows 之外先只读/浏览器）。
