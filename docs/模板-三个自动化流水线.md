# 三个自动化流水线模板（阶段③ P1-2）

> 日期：2026-10-19 · 代码基线：`16277cb`（v5.0.13 之后，工具为新增）
> 生成器：`tools/pipelines/build_jobs.py` · 执行器：`beecmd batch`（无 GUI、可审计）

## 0. 一页结论

| 模板 | 命令 | 本机实测 | 限制 |
|---|---|---|---|
| ① 合同/报告批量转 PDF（+校验） | `--kind md-pdf` | **2/2 转换成功**；校验在无字体环境返回"不可判定"（退出码 3） | 源文件必须是 Markdown；`.docx` 合同转 PDF 仍不支持 |
| ② Excel 多表汇总 | `--kind sheet-merge` | **1/1 成功**：2 个文件 / 5 行 → 汇总 xlsx | 只输出 `.xlsx`；列不一致取并集 |
| ③ 演示批量导出 | `--kind beshow` | **2/2 成功**：md → `.beshow` | 只产出蜜演自有格式；`.pptx` 导出仍需 GUI/WebEngine |

**三步通用流程**（不打开界面）：

```powershell
$env:PYTHONPATH='D:\beeofficeV'; $env:QT_QPA_PLATFORM='offscreen'
cd D:\beeofficeV

# 1) 把目录变成任务清单
python tools\pipelines\build_jobs.py --kind md-pdf --input 合同\ --output-dir 合同_out
# 2) 执行（失败不中断整批，逐条写审计）
python -m beeoffice.beecmd batch 合同_out\jobs.json --audit 合同_out\audit.jsonl
# 3) 检查审计与产物
```

## 1. 模板①：批量转 PDF（+校验）

```powershell
python tools\pipelines\build_jobs.py --kind md-pdf --input 合同 --no-verify
python -m beeoffice.beecmd batch 合同_out\jobs.json --audit 合同_out\audit.jsonl
```

实测（2 份 Markdown 合同）：

```
✅ 合同乙.md → …\合同_out\合同乙.pdf（pdf）
✅ 合同甲.md → …\合同_out\合同甲.pdf（pdf）
📝 审计流水已追加 2 条 → …\合同_out\audit.jsonl
批量完成：2/2 条成功
```

**关于校验**：默认会为每份 Markdown 生成 `verify` 任务（词元级对比 md 与 pdf）。
本机 offscreen 环境**没有字体**，PDF 提取不到文字，`verify` 会如实返回
**退出码 3（不可判定）**，batch 会把该条记为失败：

```
⚠️ 报告已写入 …（不一致 54 处；不可判定）
verify_exit=3
```

这正是设计中的诚实行为：**"不知道"不伪装成"通过"**。
在有字体的桌面/CI 上 `verify` 应返回 0；若不需要校验，用 `--no-verify`
或只跑转换。证据：`tests/fidelity/test_beecmd.py::test_verify_pdf_is_inconclusive_when_text_unavailable`。

## 2. 模板②：Excel 多表汇总

```powershell
python tools\pipelines\build_jobs.py --kind sheet-merge --input 月报 --output-dir 月报_out
python -m beeoffice.beecmd batch 月报_out\jobs.json --audit 月报_out\audit.jsonl
```

实测（两个"月度"CSV，各 2/3 行）：

```
✅ 已汇总 2 个文件 / 5 行 → …\月报_out\汇总_月报.xlsx（append）
📝 审计流水已追加 1 条
批量完成：1/1 条成功
```

生成的任务形如：

```json
{"op": "merge", "srcs": ["…/一月.csv", "…/二月.csv"],
 "out": "…/月报_out/汇总_月报.xlsx", "mode": "append"}
```

需要每个文件一个工作表时加 `--mode sheets`。

## 3. 模板③：演示批量导出

```powershell
python tools\pipelines\build_jobs.py --kind beshow --input 讲稿 --output-dir 讲稿_out
python -m beeoffice.beecmd batch 讲稿_out\jobs.json --audit 讲稿_out\audit.jsonl
```

实测（2 份 Markdown 讲稿）：

```
✅ 产品发布.md → …\讲稿_out\产品发布.beshow（beshow）
✅ 季度汇报.md → …\讲稿_out\季度汇报.beshow（beshow）
📝 审计流水已追加 2 条
批量完成：2/2 条成功
```

**为什么没有 verify**：`.beshow` 是蜜演自有格式，`beecmd verify` 不支持它与
Markdown 做词元比对（会误报不一致），所以模板只为 `md-pdf` 生成校验任务。

## 4. 边界（如实）

- 模板①只接受 Markdown/纯文本；**`.docx` → PDF 尚未支持**（需要文档渲染/打印引擎，
  当前 `beecmd` 的 PDF 路径只覆盖 Markdown）。
- 模板③只产出 `.beshow`；**`.pptx` 导出仍依赖 GUI 的 WebEngine 路径**。
- 三个模板的产物都落在 `*_out/`，审计流水 `audit.jsonl` 逐条记录
  `ts/index/op/job/ok/exit_code`，失败也记。
- 模板生成器本身有 6 条单测：`tests/unit/test_pipeline_jobs.py`（全过）。
