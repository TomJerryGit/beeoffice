# 真实文档样本回归记录

日期：2026-11-17  
版本：v5.7.12（未发布）  
环境：Windows + WPS Office COM

## 样本生成

脚本：

```text
tools/real_document_regression.py
```

生成到：

```text
D:\beeofficeV\_ptmp\analysis\real-docs\
```

| 样本 | 说明 |
|---|---|
| `real-word.docx` | 标题/正文/题注/交叉引用/脚注/尾注/页眉页脚/TOC |
| `real-excel.xlsx` | 表头样式/条件格式/冻结/打印区域 |
| `real-ppt.pptx` | 8 页、每页过渡 + 进入/强调动画 |
| `real-pdf.pdf` | 20 页，每页高亮批注烧录 |

## 真实软件验收

脚本：

```text
tools/validate_real_docs.ps1
```

结果：

```text
WORD paragraphs=3 fields=2 footnotes=1 endnotes=1
EXCEL sheets=1 lastRow=3 printArea=$A$1:$C$3
PPT slides=8 animations=16
REAL_DOCS_VALIDATION_OK
```

含义：

- Word：2 个域（TOC/REF/SEQ 等）、1 脚注、1 尾注均被 WPS 识别；
- Excel：工作表/打印区域保留；
- PPT：8 页、16 个动画均被 WPS 识别；
- PDF：20 页批注烧录输出文件有效（由 pypdf 验证）。

## 结论

本轮真实样本回归通过，但仍是**本机样本 + WPS 真实打开**，不等于：

- Win10/11 干净机验收；
- Microsoft Office 全版本兼容；
- 复杂企业模板/宏文档兼容。

这些仍需签名与干净机阶段继续验证。
