# 打包临时目录修复

日期：2026-11-26

## 现象

运行 BeeOffice.exe 时，matplotlib 的 PyInstaller runtime hook 先于应用启动：

```text
FileNotFoundError: [Errno 2] No usable temporary directory found
```

在受限环境/沙箱中 `%TEMP%` 不可写时必现。

## 修复

新增：

```text
packaging/rthook_beeoffice_dirs.py
```

在 matplotlib hook 之前执行：

1. 尝试 `LOCALAPPDATA\BeeOffice\cache`；
2. 尝试 `APPDATA\BeeOffice\cache`；
3. 尝试应用目录 `.beeoffice_cache`；
4. 尝试当前目录 `.beeoffice_cache`；
5. 创建 `temp` 与 `matplotlib` 子目录；
6. 设置 TMP/TEMP/TMPDIR/MPLCONFIGDIR。

自定义 runtime hook 在 PyInstaller 中优先于包 hook 执行。
