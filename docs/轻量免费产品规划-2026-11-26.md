# BeeOffice 轻量免费产品规划

日期：2026-11-26  
背景：单人维护、无额外设备、无资金、Windows 单机环境。

## 一、结论

**可以做，但必须缩小定位。**

不要做“免费版 WPS/Office”，而要做：

> **本地优先、轻量、免费、无账号的办公工具集。**

核心卖点不是“功能比 WPS 多”，而是：

- 本地文件，不上传；
- 免费、无广告、无订阅；
- 体积和操作比完整 Office 轻；
- 文档打开/保存可控；
- 可定制、可审计。

---

## 二、必须放弃的范围

单人、无设备、无资金时，以下方向不建议做：

- 完整 Word 排版引擎；
- 完整 Excel 计算/透视表/VBA；
- 完整 PPT 母版/动画/SmartArt；
- 实时协作、云文档、移动端；
- 企业管控、账号体系、计费；
- OCR/电子签名的商业级能力；
- 与 Microsoft Office 像素级一致；
- 多平台同时维护。

这些不是“以后再说”，而是**明确不做**，避免用户误解和自身透支。

---

## 三、产品定位

### 一句话

```text
BeeOffice = 本地轻量免费办公工具集
```

### 适合的用户

- 只需要打开/编辑/导出常见文档；
- 不想安装大型 Office；
- 在意隐私、不想上传文件；
- 能接受“复杂格式不保证 100%”。

### 不适合的用户

- 需要和同事协作编辑；
- 需要复杂 Excel 透视/宏；
- 需要企业模板/审计/权限；
- 需要法律效力电子签名。

在产品页、启动页、导出提示里都要写清楚。

---

## 四、功能边界

### 保留并做好

| 模块 | 免费版范围 |
|---|---|
| BeeWrite | 标题/段落/表格/图片/页眉页脚/PDF 导出 |
| BeeSheet | 表格/公式/基本图表/条件格式/数据验证/打印 |
| BeeShow | 基础幻灯片/图片/表格/原生图表/PPTX 导出 |
| BeePDF | 合并/拆分/批注/页面/水印/文本提取 |
| 工具 | 批量转换、文件对比、本地模板 |
| AI | 可选，用户自带 API Key，默认关闭 |

### 延后或不承诺

- Word 修订/批注的完整 Word 语义；
- Excel 透视表/宏；
- PPT 母版完整复制、动画编辑；
- OCR、数字签名、表单；
- 云同步、协作、移动端。

### 当前代码里已很多的功能

不要因为“已经写了”就都对外承诺。  
**对外只承诺高频、稳定、可维护的部分。**

## 五、技术建设原则

1. **本地单进程**
   - 不做服务端；
   - 不依赖账号；
   - 不收集遥测；
   - AI 仅 BYOK（用户自己的 Key）。

2. **文件安全第一**
   - 保存原子写；
   - 崩溃自动备份；
   - 导入永不覆盖源文件；
   - 损坏文件明确提示。

3. **单一 Windows 构建**
   - 只维护 Windows；
   - 不做 macOS/Linux；
   - 不做移动端。

4. **依赖冻结**
   - 锁定 requirements lock；
   - 专用 venv；
   - 不追最新版，按季度升级。

5. **发布可验证**
   - ZIP SHA256；
   - 安装器 SHA256；
   - 发布说明写“Unsigned / Beta”；
   - 不做自动更新，先手动下载覆盖。

## 六、发布与分发

### 主分发

```text
GitHub Releases
  - portable ZIP（推荐）
  - 安装器（可选）
  - SHA256
  - 发布说明
```

### 不做

- 官网服务器；
- 自动更新服务；
- 账号/支付；
- 应用商店（暂不申请）。

### 未签名说明

必须明确：

```text
Unsigned Beta
SmartScreen 可能提示
请核对 SHA256
```

不要伪装成“已签名正式版”。

---

## 七、维护方式

单人维护的现实策略：

- 每月 1 个版本，不追日更；
- GitHub Issues 作为唯一入口；
- 每个 Issue 标 P0/P1/P2；
- P0 只修数据丢失/无法启动/崩溃；
- 新功能每季度最多一个方向；
- 不做 24 小时响应承诺；
- 发布说明固定模板：新增/修复/已知问题/校验值。

### 自动化

已有：

```text
build_local.bat
run_tests.bat
tools/package_release.py
自托管 GitHub Actions
专用 venv
```

继续固定：

```text
测试门禁
构建门禁
发布门禁
```

## 十、资金与可持续性

当前免费可行，因为：

- 开发机器已有；
- GitHub 免费；
- 自托管 Runner 已有；
- 无服务器成本；
- 无证书成本（接受 SmartScreen 提示）。

不要为了“免费”引入：

- 广告；
- 数据出售；
- 强制账号；
- 付费墙。

如未来有收入，优先：

- 可选赞助；
- 付费支持；
- 企业定制；
- 而不是把基础功能锁起来。

---

## 十一、最大风险

1. **兼容性预期过高**  
   用户拿它和 Office 比，会失望。  
   解决：明确“轻量工具集”，不承诺全兼容。

2. **数据丢失**  
   一次严重丢文档就会毁掉信任。  
   解决：备份、原子写、恢复、测试。

3. **单人 burnout**  
   解决：功能冻结、季度节奏、明确不做清单。

4. **未签名/SmartScreen**  
   解决：透明披露、SHA256、portable ZIP。

5. **依赖升级破坏构建**  
   解决：venv、lock、固定 CI。

---

## 十二、最终建议

**可以做成一个有意义的小产品，但不要再往“全功能 Office”方向堆。**

最合适的形态：

```text
Windows 单机
免费
本地优先
无账号
无广告
轻量工具集
明确边界
可持续维护
```

一句话：

> **不是做一个小 WPS，而是做一个“够用、干净、能长期维护”的本地办公工具。**
