## ✨ 功能特性

### 📝 蜜写 BeeWrite

- Markdown 编辑与实时预览
- 支持表格、代码块、任务列表等扩展语法
- 目录（TOC）自动生成
- 导出 DOCX / PDF / HTML
- 从 Word 文档导入
- **图片往返保留**：富文本 ↔ Markdown 往返时图片不丢失
  - 富文本图片自动转为 `![](path)` Markdown 语法
  - Markdown 里的 `![](path)` 切回富文本时自动重新加载
  - 从 DOCX 导入时提取内嵌图片到 `<name>_media/` 目录
  - 粘贴 / 插入的图片保存到文档同目录的 `<文档名>_media/`
    （原先只落在 `%TEMP%`，系统清理后图片永久失效 —— 阶段 2 已修）
- AI 辅助写作（续写、润色、总结、关键词提取）
- 所见即所得模式：段落格式、字符底纹、多级列表、表格可视化编辑
- 批注 / 书签 / 修订模式
- 超链接 / 交叉引用 / 数学公式 / 文本框
- 水印 / 页码 / 页面设置（页边距单位已统一为 **mm**）
- ❌ **页眉页脚：已移除**（曾是假功能）。原实现只是把 `<!-- header: X -->` 当作**正文**
  插入，提示却写"导出 Word 时生效"，且全仓没有任何消费者
- 🟡 数据变量绑定（`{{ 数据源.字段 }}`）—— 功能存在，本会话未实测

### 📊 蜜算 BeeSheet

- CSV / Excel 数据导入导出
- 完整公式引擎：SUM、AVERAGE、IF、VLOOKUP、SUMIFS 等 80+ 函数
- 自然语言生成公式（如"求和A1到A10"自动生成 `=SUM(A1:A10)`）
- 图表生成：折线图、柱状图、饼图、散点图、面积图、雷达图
- 大文件分块加载（100MB+，**支持取消**）
- 数据清洗（去重、空值处理、分列）
- 数据透视表
- 条件格式（数据条 / 色阶 / 图标集）
- 公式审计（追踪引用 / 从属）
- 筛选 / 排序 / 数据验证 / 名称管理器
- ❌ **冻结窗格：已移除**（曾是假功能）。原实现只把表头 `setSectionResizeMode(Fixed)`，
  **没有任何滚动冻结效果**
- ❌ **宏录制与播放：已移除**（从未实现）。`BeeSheetView` 里根本没有对应方法，
  点击只弹出"当前表格不支持宏录制"

### 🎥 蜜演 BeeShow

- 幻灯片编辑与全屏播放
- 7 种主题 + 自定义背景
- 4 种切换动画：淡入、滑入、缩放
- 演讲者视图（备注 + 下一页预览 + 进度条）
- 排练计时
- 导出 PPTX / PDF / HTML / PNG 图片序列 / GIF
  （🟡 **GIF 未经实测验证**；其余已在阶段 2 修好并配了产物级测试 ——
  原先 PNG 与 HTML 导出都是"点了没反应/假报成功"）
- 拖拽排序幻灯片（**保留该页的评论/样式/图片标记** —— 阶段 2 修复前会永久删除）
- ❌ **激光笔 / 画笔：已移除**（曾是假功能）。全仓没有任何鼠标事件处理，
  `L` 只切换一个静止红点、`P` 只翻转一个没人读取的布尔量

### 📄 PDF 批注

- 打开 PDF 进行批注、高亮、下划线、删除线、文字注释
- 支持撤销（**区分页码**）
- 保存为 `.beeanno` 文件（旁挂）或烧录到 PDF
- 多窗口管理

### ☁️ 云同步

- WebDAV 支持
- OneDrive 支持（基于 Microsoft Graph API）
- Google Drive 支持（基于 Google Drive API v3）
- 自动同步与手动同步
- 同步进度显示
- ❌ **冲突检测：不存在**，且当前同步是**纯单向上传**（`download()` 从未被调用）。
  阶段 4.5 已把它改成带过滤的**如实计数**（"已上传 N / 跳过 K / 失败 F"），
  不再无过滤上传、也不再一律报"同步完成"；"双向同步 + 冲突策略"**尚未实现**

### 📱 移动端访问

- 内置 HTTP 服务器，手机浏览器即可查看文档
- 响应式 Web 界面，支持文档列表与预览
- 动态端口分配，避免冲突

### 🔌 插件系统

- 动态发现与加载插件
- 插件市场：安装、卸载、启用/禁用
- 符合 `Plugin` 基类的接口规范

### 🎨 界面与体验

- 明暗双主题
- 4 种强调色（琥珀、海洋、森林、日落）
- 中英文国际化
- 命令面板（Ctrl+Shift+P）
- 标签页拖拽合并
- 未保存状态标记
- 自动保存（每 5 分钟）
- 文件监视（外部修改提示）

### ✅ 功能实现状态说明（请以本节为准）

上面这份清单**不是逐条实测过的**。为避免"清单说能用、实际点不动"，这里说明
标注规则与**本会话实测确认**的部分：

| 标记 | 含义 |
|---|---|
| ✅ | 有产物级/行为级测试覆盖，或本会话实测确认 |
| 🟡 | 功能存在但**未经实测**（只读过代码） |
| ❌ | **已确认为假功能 / 未实现**（上方各条已就地标注） |

本会话**实测确认已修好**（原先要么不可用、要么会丢数据）：
PNG 序列导出、蜜写 HTML 导出、蜜写批注/书签重开后保留、拖动排序保留评论/样式、
插入图片不再只落 `%TEMP%`、MD→DOCX 的图片与超链接、页边距单位（mm）、
`=LOG10(...)` 不再被改写、`$` 绝对引用与反向范围、聚合逗号参数、循环引用不再

PPTX 不再每页重启一次 Chromium、导出动态数字不再显示 0、
云同步改为带过滤的如实计数。

本会话**确认并移除**的假功能：页眉页脚、冻结窗格、宏录制与播放、激光笔/画笔。
**仍未做完整审计**：完整清单见
[BeeOffice-分析报告.md](BeeOffice-分析报告.md) 的 §5.1，规划 §4.3 要求把那张表

## 🚀 快速开始

### 环境要求

- Python 3.9 或更高版本
- Windows / macOS / Linux

### 安装

```bash
# 克隆仓库
git clone https://github.com/TomJerryGit/beeoffice.git
cd beeoffice

# 安装依赖
pip install -r requirements.txt

# 启动
python -m beeoffice.main
