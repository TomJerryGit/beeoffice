# BeeSheet 参考 WPS Excel 功能优化路线图

日期：2026-11-16  
基线：BeeOffice v5.4.7 Beta  
范围：BeeSheet（Excel 表格）功能与 Ribbon 体验

## 1. 目标与原则

参考 WPS Excel 的页签与功能组织，不复制其品牌素材：

1. 页签对齐：开始 / 插入 / 页面 / 公式 / 数据 / 审阅 / 视图 / 工具 / AI；
2. 先补“表格真正天天用”的能力：打印、公式、数据、保护、视图；
3. 每个功能必须有 `xlsx` 往返测试与撤销/重做；
4. 大表格性能优先，网格按需扩展，不一次性分配百万行；
5. WPS 的会员/效率生态不强行复制，保留 BeeOffice 本地优先。

## 4. 路线图

| 任务 | 验收标准 |

| 打印设置补全 | 页眉页脚、打印网格线/标题、分页预览、插入分页符 |
| 新增“审阅”页签 | 批注、拼写检查、保护工作表/工作簿 |
| 公式页补全 | 函数分类库、显示公式、错误检查、计算选项 |
| 数据工具补全 | 删除重复项、分列、分类汇总、合并计算 |
| 单元格格式 | 格式刷、单元格样式库、自动换行、最优列宽 |

## 5. 技术前置

1. **虚拟网格**：行/列按滚动增长，不在 DataFrame 中预分配百万空行；
2. **公式引擎**：函数分类、错误码、依赖图、增量重算；
3. **打印引擎**：页面布局、分页、页眉页脚、打印区域；
4. **图表/对象层**：图表、形状、图片统一选中/缩放/撤销；
5. **xlsx 往返**：样式、合并、条件格式、打印设置、图表不丢；
6. **撤销/重做**：所有数据/格式操作可撤销；
7. **性能测试**：1 万行/100 列/公式链的打开、排序、筛选。

## 6. 建议执行顺序

```text
第 1 周：页面页签 + 打印预览/页边距/纸张/打印区域
第 2 周：审阅页签 + 保护/批注/拼写 + 公式页补全
第 3 周：数据工具（重复项/分列/分类汇总/合并计算）
第 4 周：视图开关 + 网格按需扩展 + xlsx 往返测试
第 5–8 周：图表/透视表/条件格式管理器/页面装饰
第 9 周起：AI 表格能力与效率模板
```

## 7. 不承诺项

- 不完整复刻 WPS 的会员/ERP/云协作生态；
- 不复制 WPS 品牌图标、模板、素材；
- 不在公式/打印/xlsx 往返未稳定前上线复杂图表；
- 百万行、宏、股票数据等能力需单独性能与安全评估。

## 8. 结论

BeeSheet 已有 Ribbon、公式、排序筛选、图表、透视表和基础 AI 入口，但离 WPS Excel 的“表格闭环”还差：

```text
页面/打印 → 公式补全 → 数据工具 → 保护审阅 → 视图/网格 → 图表透视增强 → AI
```

优先补 **页面页签、审阅页签、数据工具和网格扩展**，比继续增加装饰按钮更重要。
