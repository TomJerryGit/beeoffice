# BeeOffice v5.6.0

发布日期：2026-11-16  
Release：https://github.com/TomJerryGit/beeoffice/releases/tag/v5.6.0  
发布状态：**Beta / Unsigned**（未签名；未做干净机验收；Win11 未验证）

## 重点更新（Wave 3：PDF P0）

### 页面/缩略图
- PDF Ribbon：开始 / 标注 / 页面 / 保护 / 转换；
- 左侧页面缩略图，点击跳页；
- 页面管理器：拖拽排序、删除、旋转、另存新 PDF；
- 合并/拆分/提取/替换/裁剪/页面大小复用 PDF 工具箱。

### 批注
- 高亮/下划线/删除线/批注/文本框/箭头/签名/矩形/圆形/直线；
- 批注颜色、线宽 1–12；
- 撤销/重做、显示/隐藏；
- 导入/导出 `.beeanno`；
- 保存/烧录保留线宽。

### 保护/转换
- 加密/权限 GUI；
- 水印 GUI；
- PDF→图片、PDF→TXT、图片→PDF；
- 连续阅读基础入口。

### 工程化
- 全量测试 **1611 passed**；
- 安全扫描高危 0；
- 依赖锁与 CycloneDX SBOM 保持；
- CI 全量测试/安全扫描/核心覆盖率门禁。

## 已知边界

- 连续阅读仍是基础模式，未做真正的多页拼接；
- 任意 PDF 文字/排版编辑未实现；
- 禁止复制/打印权限未做细粒度 GUI；
- 安装包未签名。

## 未验证项（重要）

- **未做 Windows 10/11 干净机安装验收**；
- **Windows 11 未验证**；
- 安装包**未签名**，SmartScreen 会提示未知发布者。
