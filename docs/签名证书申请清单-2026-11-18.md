# BeeOffice 代码签名证书申请清单

日期：2026-11-18  
目标：v6.0 Stable 前完成 exe/安装器签名与时间戳。

## 1. 证书类型

| 类型 | 用途 | 说明 |
|---|---|---|
| OV Code Signing | 通用发布 | 需企业/个人身份核验 |
| EV Code Signing | SmartScreen 更快建立信誉 | 成本更高、硬件令牌 |
| Azure Trusted Signing | 云签名 | 按需订阅，适合 CI |

建议：先申请 OV；如预算允许用 Azure Trusted Signing 做 CI。

## 2. 采购前准备

- [ ] 企业/个人主体证明
- [ ] 电话/邮箱核验
- [ ] 营业执照/登记信息
- [ ] 私钥存储方案（HSM/云签名，禁止明文仓库）
- [ ] 时间戳服务 URL（RFC3161）
- [ ] 签名工具版本与 CI 集成方案

## 3. 签名范围

```text
dist/BeeOffice/BeeOffice.exe
release-archive/BeeOffice-Setup-vX.Y.Z.exe
随包 DLL/工具（如有）
```

## 4. 签名流程

1. 构建产物；
2. 对每个产物执行 signtool sign；
3. RFC3161 时间戳；
4. `signtool verify /pa`；
5. 记录证书指纹、时间戳、哈希；
6. 上传发布资产。

## 5. 验收标准

```text
所有 exe 已签名
时间戳存在
verify /pa 通过
SmartScreen 状态记录
证书指纹写入发布说明
```
