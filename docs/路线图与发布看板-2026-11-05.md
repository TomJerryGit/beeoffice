## 4. 重排后的阶段

### S4（2026-11-05 → 11-18）：UI/UX 与质量门禁

目标：让主界面和核心对话框“可发现、可键盘操作、可回归”。

- F1 UI 审计：菜单/工具栏/对话框/状态栏，输出 TOP 20；
- F2 修复 TOP 15 UI 缺陷；
- F3 键盘导航/焦点/快捷键一致性；
- F4 高 DPI（100%/150%/200%）与中英文布局；
- F5 关键页面截图基线；
- G1 将 UI 冒烟/安装冒烟加入门禁。

验收：
- UI 审计报告 + 修复清单；
- 核心流程（新建/打开/保存/导出/关闭）可纯键盘完成；
- 三种 DPI 无截断/重叠；
- 截图基线可重复生成；
- 全量测试不回归。

### S5（11-19 → 12-02）：兼容 TOP10 + 干净机验收

- D1 扩充真实语料（DOCX/XLSX/PPTX 各 +20）；
- D2 兼容分级：P0 崩溃/数据丢失、P1 版式、P2 视觉；
- D3 修复 TOP10；
- 安装器在干净 Windows VM 完成安装/启动/卸载；
- 安装包尝试签名（无预算则继续自签名测试并标注）。

### S6（12-03 → 12-16）：兼容 TOP20 + Beta + v5.5.0 准备

- D4 修复 TOP11–20；
- G2 外部 Beta（≥20 人）；
- C3/C4 崩溃诊断与首次启动引导；
- v5.5.0 RC。

### 暂缓

## 5. 当前阻塞

| 阻塞 | 影响 | 应对 |

| 无代码签名预算 | SmartScreen 警告、无法声明正式签名 | 自签名仅测试；后续申请 OSS 签名或预算 |
