蜜演 BeeShow 对标 WPS 演示 · 实现路线图
版本：v1.0
日期：2026-09-17
目标：6 周内将蜜演从「Markdown 演示工具」升级为「AI 驱动 + 专业版式 + 协作演示」的完整方案

一、总览
基于 WPS 演示的最新能力（AIPPT 对话式创作、HTML 专业模式、智能重用幻灯片、多人实时协作、远程同步演示）与蜜演现状（8 个文件拆分完成），规划为 5 个阶段、14 个任务，总工时约 45 个工作日。

关键路径：1.1 AI大纲 → 2.1 版式系统 → 3.1 PPTX原生映射 → 3.2 字体子集化

二、阶段与任务
阶段一：AI 能力升级（1.5 周）
任务	目标	交付物	依赖	工时
1.1 AI 大纲接入 LLM	从硬编码模板升级为真实 LLM 调用，支持意图澄清与多轮修改	beeshow_ai_service.py（新建）	LLM API	5d
1.2 AI 演讲稿生成	基于每页内容自动生成演讲备注	beeshow_notes_mixin.py 扩展	1.1	2d
1.3 AI 配图建议	根据文本推荐配图，提供 3-5 张候选	beeshow_ai_mixin.py 扩展	1.1	2d
阶段二：版式系统与编辑器增强（2 周）
任务	目标	交付物	依赖	工时
2.1 预定义版式系统	提供 8-12 种专业版式，替代纯 Markdown 手写	beeshow_layout_mixin.py（新建）	无	4d
2.2 预览区元素级操作	点击选中元素，弹出工具栏修改样式	beeshow_slide_mixin.py 扩展	2.1	4d
2.3 图片拖拽调整	拖拽调整图片大小与位置	beeshow_slide_mixin.py 扩展	2.2	3d
阶段三：导出质量提升（1.5 周）
任务	目标	交付物	依赖	工时
3.1 PPTX 原生元素映射	DOM 测量 + 原生形状映射，保留文本可编辑	beeshow_pptx_engine.py（新建）	2.1	6d
3.2 中文字体子集化	嵌入字体，跨机器不跑版	beeshow_pptx_engine.py 扩展	3.1	3d
阶段四：协作与演示增强（2 周）
任务	目标	交付物	依赖	工时

图表 8：风险 - 阶段矩阵
阶段	风险	概率	影响	缓解措施
一	LLM API 成本/延迟	中	高	支持本地模型（Ollama）备选
一	LLM 输出格式不稳定	高	中	JSON Schema 约束 + 重试
二	元素级操作破坏 Markdown	中	高	保留原始 Markdown，修改存为注释
二	图片拖拽坐标漂移	中	低	用相对坐标（百分比）而非像素
三	DOM 测量不准确	高	高	用 Playwright headless Chromium
三	字体子集化兼容性	中	中	优先支持 Noto Sans SC
四	WebSocket 同步延迟	低	中	只广播增量（页码）
四	版本历史占用内存	中	低	只保留最近 50 版
五	平滑动画兼容性	中	低	仅对 id 相同元素启用
五	视频文件过大	中	中	导出时压缩或外链
