# 反馈与维护流程

日期：2026-11-27  
适用：BeeOffice 免费 Beta，单人维护。

## 一、唯一反馈入口

GitHub Issues：

- Bug：使用 `Bug report` 模板；
- 数据丢失/无法启动：使用 **P0 数据安全** 模板；
- 功能建议：使用 `Feature request` 模板。

不提供：

- 24 小时响应；
- 电话/微信支持；
- 远程桌面；
- 对商业文档的赔偿承诺。

## 二、优先级

### P0：只修这一类

- 文档内容丢失；
- 文件损坏/无法打开且无法恢复；
- 保存失败导致内容丢失；
- 启动崩溃/无法启动；
- 安装/升级导致无法使用；
- 安全问题。

处理目标：

```text
7 天内确认
下一个补丁/Pre-release 修复
```

### P1：可修，但不阻塞发布

- 打开/导出格式明显错误；
- 常用编辑操作不可用；
- 表格/批注/恢复功能异常；
- 明确的性能崩溃。

### P2：排期或关闭

- 新功能；
- 与 Office 兼容性细节；
- 界面美化；
- 超出免费边界的请求。

### 不修

- Excel 透视表/VBA；
- 完整 Word 修订/复杂排版；
- PPT 完整母版/动画；
- 云协作、移动端；
- OCR、电子签名；
- 与 Microsoft Office 像素级一致。

## 三、发布节奏

```text
每月最多 1 个版本
只发 Pre-release Beta
稳定版需额外满足：
  - 连续 2 个 Pre-release 无 P0
  - 干净 Windows 机器安装/卸载通过
  - 核心真实语料打开/保存通过
  - 已知限制写清楚
```

## 四、发布前检查清单

```text
[ ] 全量测试通过
[ ] CI success
[ ] ZIP testzip OK
[ ] 打包 exe 启动存活
[ ] 安装器生成
[ ] SHA256 写入 Release
[ ] 发布说明列出已知限制
[ ] 标注 Pre-release / Unsigned
[ ] 不承诺未验证的兼容性
```

可用命令：

```powershell
cd D:\beeofficeV\_ptmp\s4
run_tests.bat
build_local.bat
```

## 五、P0 处理流程

1. 要求用户先备份原文件与日志；
2. 用最小复现文件复现；
3. 先写失败测试；
4. 修复；
5. 全量测试；
6. 发布 Pre-release；
7. 在 Issue 中说明修复版本与剩余限制。

## 六、不收集

- 不收集用户文档；
- 不收集使用行为遥测；
- 不要求账号；
- 不向第三方上传文件。

## 七、维护原则

> 只修 P0，少量 P1；不做超范围功能。

每月检查一次：

- 未关闭 P0 数量；
- 崩溃/启动失败报告；
- 下载量与反馈；
- 是否需要暂停新功能、只做稳定化。
