# BeeOffice 阶段二 / 阶段三 + 信任建设优化计划

日期：2026-11-19  
基线：v5.8.32  
目标：从“可用 Beta”推进到“可签名的 v6.0 Stable 候选”，再进入产品化。

---

## 一、总体顺序

```text
Phase A（0–4 周）   信任止血：WebEngine + 签名 + MS Office 验收环境
Phase B（1–3 月）   Word / Excel 深度
Phase C（3–5 月）   PPT / PDF 深度
Phase D（5–8 月）   产品化与生态
```

原则：

1. 先解决“敢不敢交付”，再解决“功能强不强”。
2. 每个阶段有硬门禁，不达标不进入下一阶段。
3. 外部依赖（证书、Office、OCR）提前采购/申请。
4. 单人项目必须砍范围：Word/Excel 优先，PPT/PDF 保持 Beta。

---

## 二、Phase A：信任止血（0–4 周）

### A1. WebEngine 一次性崩溃根治

目标：`pytest tests` 连续 5 次稳定通过。

步骤：

1. 用 `tools/run_tests_per_file.py` 建立基线；
2. 在崩溃时启用 Windows minidump / WebEngine 日志；
3. 二分执行顺序，定位首个“状态污染”测试；
4. 检查 QWebEngineProfile/Page 生命周期、QApplication 重建、插件扫描事件重入；
5. 评估 Chromium flags：`--single-process`、`--disable-gpu`、`--disable-software-rasterizer`；
6. 修复根因；无法修复则引入 pytest 子进程隔离作为正式方案；
7. 验收：一次性全量 5 连跑 + 分段全量。

**门禁 G0**

```text
一次性 pytest tests 连续 5 次全绿
或 CI 强制分段/按文件隔离且文档明确
```

### A2. 代码签名证书 + 时间戳

采购选项：

- OV Code Signing（成本较低）
- EV Code Signing（SmartScreen 信誉更快）
- Azure Trusted Signing（适合 CI）

步骤：

1. 准备主体资质、电话/邮箱核验；
2. 采购证书/云签名；
3. 配置私钥安全存储（HSM/云，禁止入仓库）；
4. CI 签名脚本：
   - 签 `BeeOffice.exe`
   - 签安装器
   - 签附带 DLL
5. RFC3161 时间戳；
6. `signtool verify /pa`；
7. 记录证书指纹、时间戳、SHA256；
8. SmartScreen 状态记录。

**门禁 G1**

```text
所有交付 exe 已签名
时间戳存在
verify /pa 通过
SmartScreen 状态已记录
```

### A3. Microsoft Office 视觉验收

环境：

- Windows 10 22H2 + Office 2016/2019
- Windows 11 23H2 + Microsoft 365
- 普通用户、Defender 开启

步骤：

1. 建立 Office COM 验收脚本；
2. 导入/导出后自动打开；
3. 截图 + 页数/表格/对象计数；
4. 重点验证：
   - Word：分页、页眉页脚、表格、TOC
   - Excel：公式、条件格式、图表、打印
   - PPT：母版、占位符、图表、表格、动画
5. 建立 MS Office 差异报告；
6. 失败样本进入缺陷池。

**门禁 G2**

```text
MS Office 打开成功率 ≥99%
关键对象计数一致
视觉差异有清单
```

### A4. 干净机验收

- Hyper-V/Packer 模板；
- 非管理员安装/运行；
- 静默安装/卸载/残留检查；
- 与签名联动。

## 三、Phase B：Word / Excel 深度（1–3 月）

|---|---|---|
| W1 | 浮动对象/文字环绕 | 图片/文本框可环绕、保存重开不丢 |

|---|---|---|
| E1 | 公式函数补齐 | 常用函数覆盖 ≥95% |

| E3 | 图表编辑 | 数据源/类型/样式可改 |
| E4 | 透视表 | 创建/刷新/字段拖拽 |
| E5 | 条件格式完整 | 规则管理、优先级、数据条/图标集 |

## 十、结论

> 阶段二/三不是“再加更多按钮”，而是把 BeeOffice 从“能演示”推进到“能交付”：
> **签名可信、Office 兼容、对象可编辑、性能有基线、生态可扩展。**
