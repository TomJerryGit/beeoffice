# 覆盖率口径：核心 100%，GUI 尽量高（2026-11-11）

## 为什么不是全仓 100%

全仓包含 Qt 弹窗、菜单、打印、安装器、构建脚本、WebEngine/WebDAV/
Google Drive/OneDrive 等外部集成。强行 100% 需要大量 mock 和
`# pragma: no cover`，容易产生“数字漂亮、真实路径没验证”的假覆盖。

本项目的口径：

| 层 | 目标 | 说明 |
|---|---:|---|
| 核心逻辑/数据/协议 | **100%** | 必须真实执行，不靠 pragma |
| GUI 交互 | 尽量高 | 以冒烟 + 关键路径为主，不设 100% |
| 全仓总体 | 只报告 | 不作为唯一发布条件 |

新增核心模块时，必须同时：

1. 加入 `CORE_MODULES`；
2. 补到 100% 语句覆盖；
3. 在 PR/提交说明中写明。

## 命令

```powershell
python -m pytest tests `
  --cov=beeoffice `
  --cov-report=json:coverage.json `
  --cov-report=term

python tools/coverage_gate.py coverage.json
```

- 核心模块未到 100%：退出码 1；
- 全仓/GUI 覆盖率只打印，不再用 `--cov-fail-under` 卡整体。
