# 真实语料采集模板与登记清单

日期：2026-11-18  
用途：Phase 1 保真回归的真实文档采集、脱敏与登记。

## 一、采集原则

1. 来源合法，取得使用授权；
2. 必须脱敏：人名、公司名、电话、地址、账号、金额；
3. 原始文件不入库；
4. 登记哈希与标签，不登记敏感内容；
5. 每份样本可追溯到授权记录。

## 二、目录约定

```text
tests/corpus/raw/<module>/<id>-<slug>.<ext>
tests/corpus/reports/<id>-roundtrip.json
```

示例：

```text
tests/corpus/raw/word/word-006-real-report.docx
tests/corpus/reports/word-006-roundtrip.json
```

## 三、登记字段

```json
{
  "id": "word-006",
  "kind": "word",
  "status": "ready",
  "synthetic": false,
  "source": "customer-authorized",
  "hash_sha256": "<sha256>",
  "tags": ["header-footer", "toc", "table", "image"],
  "pages": 20,
  "complexity": "high",
  "license": "internal-regression",
  "sensitive": false,
  "notes": "已脱敏，保留版式"
}
```

## 四、脱敏清单

- [ ] 删除/替换人名
- [ ] 删除/替换公司名
- [ ] 删除电话/邮箱/地址
- [ ] 删除账号/身份证/银行卡
- [ ] 删除金额/合同编号
- [ ] 删除图片中可识别信息
- [ ] 元数据清理（作者/公司）
- [ ] 另存为新文件

## 五、采集配额

| 模块 | 目标 | 当前真实 | 当前合成 |
|---|---:|---:|---:|
| Word | 10 | 0 | 2 |
| Excel | 10 | 0 | 1 |
| PPT | 5 | 0 | 1 |
| PDF | 5 | 0 | 1 |

## 六、验收流程

```text
登记 → OOXML/PDF 校验 → 导入 → 编辑 → 导出
→ WPS 打开 → MS Office 打开 → 差异报告
```

通过标准：

- 无内容丢失；
- 页数/表格/域/脚注/图片可核对；
- 关键样式可接受；
- 失败样本进入缺陷池。
