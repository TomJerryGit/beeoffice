1. 先做 `beeoffice/pdf_backend.py` 适配层，禁止上层直接 import fitz；
2. 先迁移页面结构操作（合并/拆分/旋转/裁剪/删除/插入/替换）；
3. 再迁移文本/图片提取与渲染；
4. 最后迁移批注/签名/水印（高风险，允许降级）；
5. 全量测试通过后删除 PyMuPDF 依赖与所有 import。
