## 89 处 Qt `.exec()` 为什么不是高危

这些是：

```python
dialog.exec()      # QDialog 模态事件循环
menu.exec(pos)     # QMenu 弹出
app.exec()         # Qt 主事件循环
```

输入来源是本地鼠标/键盘事件和 Qt 控件状态，不是 Python 代码字符串，**不会执行任意代码**。  
扫描规则应排除 `\.exec\s*\(`，或只匹配裸 `exec(` / `exec (`。
