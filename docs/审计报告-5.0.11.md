## 2. 发现的问题（按严重度）

### 2.1 【高危 · 已修】草稿目录不可用 → 启动检查抛异常
* **现象（实测 A）**：把 `BEEOFFICE_DRAFT_DIR` 指向一个**同名文件**（或 home 只读）时，
  `drafts_dir()` 直接 `mkdir()` → `FileExistsError`；`list_drafts()` 同样抛。
  而 `_check_recoverable_drafts` 是**启动定时器**里的槽函数 →
  恢复功能会变成"启动报错"（最坏情况下崩溃/刷错误日志）。
* **影响**：真实场景存在（只读 home、便携盘、路径被占）。
* **修复**：`drafts_dir()` 失败不再抛；`list_drafts()` 读不了返回空表；
  `record()` 写不了返回 `False`。已加回归：
  `test_drafts_dir_survives_when_path_is_blocked`、`test_record_returns_false_when_unwritable` ✓

### 2.2 【高危 · 已修】`ai_errors._has_status` 只改调用、漏定义（**我自己引入的回归**）
* **现象（实测 A）**：`ruff --select F821` 报 4 处 `Undefined name _has_status`；
  **7 条 AI 报错归因测试全红**、**3 个门禁失败**（`ai-settings` / `p1_xls_undo_sync` / `media-fallback-failfast`）。
* **根因**：我把"去掉 `"404" in text` 子串误判"的补丁拆成两次编辑，
  第一次（插入函数）**失败**而我没复核，第二次（改调用处）成功了。
  这正是我这轮反复犯的"**只看命令返回、不看结果**"的老毛病。
* **修复**：补上 `_has_status`（按数字边界匹配）；复跑 74 条相关测试全绿 ✓

### 2.3 【中危 · 已修】`beecmd` 遇到损坏的 `.pptx` 直接甩 traceback
* **现象（实测 A）**：`convert broken.pptx --to beshow` → exit 1 但 stderr 是完整 traceback
  （`pptx.exc.PackageNotFoundError`）。
* **修复**：`main()` 兜底 `except Exception` → 一句人话 + 提示"确认文件完好/未加密"；
  已加回归（子进程 + stderr 落文件，断言**无 Traceback**）✓

### 2.4 【中危 · 已修】`.pptx` 契约测试失效（旧测试断言"不支持"）
* **现象（实测 A）**：`test_p1b_usability.py::test_unsupported_extension_shows_message_and_skips_recent[幻灯片.pptx]` 失败。
* **原因**：P0-1 让 `.pptx` 变得**支持**了，旧测试的前提不再成立 —— 不是产品 bug，是**测试需要跟着改**。
* **修复**：从"不支持"参数表里移除 `.pptx`（`.doc` / `.xlsm` 保留）✓

### 2.5 【低危 · 已修】AI 错误归因的子串误判（端口号含 404）
* **现象（实测 A）**：`"404" in text` 会把 `localhost:4040` 的拒连误判成 HTTP 404。
* **修复**：改按数字边界（`(?<!\d)404(?!\d)`），401/403/429 同处理 ✓

### 2.6 【中危 · ✅ 已修】3 处死变量（`F841`）—— 其中 1 处是真缺陷
| 位置 | 变量 | 判断 | 处理 |
|---|---|---|---|
| `beesheet_print_mixin.py:273` | `total_w` | **多余赋值**（后续逻辑改用别的量） | 已删除（打印测试 20+31 条确认排版未变 ✓） |
| `beeshow_font_subset.py:476` | `existing_ids` | **忘用 = 真缺陷** ⚠️：注释说要读 rels 避免 rId 冲突，实际却固定用 `rId{100+i}` → 目标文件已有 `rId100+` 时会**撞号**，PowerPoint 可能报"需要修复" | 已修复：改为从"现有最大 rId + 1"开始编号（无冲突时行为与原来一致） |
| `beewrite_formula.py:256` | `text` | **多余赋值**（`fig.text` 调用有副作用） | 已删除赋值、保留调用 ✓ |

### 2.7 【中危 · ✅ 已有护栏】170 处 `except:` / `except Exception:`
* 已知技术债（`BLE001`）。开发期会掩盖真实异常（这轮就被"宽泛 except 吞掉日志"坑过）。
* **已落地护栏**：新增门禁 `error-hygiene` —— 对**新增模块**
  （`drafts.py`/`beecmd.py`/`ai_errors.py`/`beeshow_pptx_import.py`）强制：
  * 禁裸 `except:`；
  * 宽泛 `except Exception:` 必须显式 `# noqa: BLE001`（= 已审查的兜底）；
  * **宽泛 except 后不许静默 `pass`**（必须记日志/返回可观察结果）。
* **存量不动**（有意取舍：全量改风险大且污染 diff）；以后新模块加进清单即可。
