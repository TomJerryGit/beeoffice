## 2. 生成命令

```powershell
$env:QT_QPA_PLATFORM='offscreen'
$env:QT_QPA_FONTDIR='C:\Windows\Fonts'

python tools/ui_screenshots.py --out docs/ui-baseline/2026-11-05
```
