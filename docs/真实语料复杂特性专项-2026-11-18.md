## 二、关键发现：PPT 图表/表格往返丢失（已修复）

5 份样本均为：

```text
导入前：1 个原生图表 + 1 个原生表格
导入再导出后：0 个原生图表 + 0 个原生表格
```

| 样本 | 图表前→后 | 表格前→后 | 页数 |
|---|---:|---:|---:|
| 人工智能 | 1 → 0 | 1 → 0 | 8 → 8 |
| 新能源汽车 | 1 → 0 | 1 → 0 | 8 → 8 |
| 跨境电商 | 1 → 0 | 1 → 0 | 9 → 9 |
| 生物医药 | 1 → 0 | 1 → 0 | 8 → 8 |
| 智能家居 | 1 → 0 | 1 → 0 | 8 → 8 |

**原判定：P0 保真缺陷。2026-11-19 已修复并回归通过。**

原因：

- PPTX 导入把图表/表格降级为文本或省略；
- 导出只重建文本页，未恢复原生 Chart/Table。

页数保持，文本略增（占位文本），但对象级丢失。
