# BeeOffice 发布门禁清单

适用：Beta / RC / Stable  
原则：缺一项即禁止发布。

## 构建

- [ ] 干净工作区，版本号一致
- [ ] 全量测试通过
- [ ] release_check 通过
- [ ] ZIP testzip 通过
- [ ] 打包 exe 冒烟存活
- [ ] 安装器编译成功

## 语料门禁

```powershell
python tools\release_check.py --with-corpus
```

RC/Stable 追加：

```powershell
python tools\release_check.py --with-corpus --corpus-strict
```

- [ ] 语料清单存在
- [ ] 已登记样本 OOXML/PDF 完整性通过
- [ ] strict 模式无缺失样本

## 保真

- [ ] 真实语料回归通过率达标
- [ ] OOXML schema 校验 100%
- [ ] WPS 打开通过
- [ ] MS Office 打开通过（RC/Stable）
- [ ] 关键字段/页数/样式断言通过

## 签名

- [ ] exe/安装器/附带 DLL 已签名
- [ ] RFC3161 时间戳
- [ ] signtool verify /pa 通过
- [ ] SmartScreen 状态记录

## 干净机

- [ ] Win10 22H2 安装/启动/卸载
- [ ] Win11 23H2 安装/启动/卸载
- [ ] 非管理员运行
- [ ] Defender 开启
- [ ] 残留检查

## 交付

- [ ] SHA256
- [ ] SBOM
- [ ] 发布说明
- [ ] 已知问题
- [ ] 回滚包
- [ ] 更新通道

## 证据归档

```text
测试日志
schema 报告
WPS/MS 截图或 COM 输出
签名验证输出
干净机日志
```

## 结论

```text
门禁通过 → RC/Stable
任一失败 → 仅内部 Beta
```
