# 自动保存 / 崩溃恢复

日期：2026-11-26

## 行为

- 每 60 秒检查所有标签；
- 仅保存有未保存修改的 Word/Markdown；
- 快照写入缓存目录：
  - `BEEOFFICE_CACHE_DIR/recovery`
  - 或 `%LOCALAPPDATA%\BeeOffice\recovery`
- 快照文件：`session.json`，原子写。

## 启动恢复

- 启动后 1.5 秒检查；
- 有快照时询问是否恢复；
- 恢复 Word/Markdown 标签与文件路径；
- 恢复后清理快照。

## 修复

- 未命名新文档不再触发自动“另存为”弹窗，只依赖恢复快照；
- 测试环境通过 `BEEOFFICE_DISABLE_RECOVERY=1` 关闭自动提示。

## 验证

```text
tests/unit/test_recovery_store.py
全量：1717 passed
```

## 边界

- Excel/PPT 尚未纳入快照；
- 恢复的是内部文本，不保证图片/对象全部还原；
- 快照为单会话覆盖，不做多历史版本。
