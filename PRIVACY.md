# BeeOffice Privacy Policy

BeeOffice is a local-first office suite. Documents are stored and processed on
the user's machine by default.

## Network access

The application may access the network only when the user explicitly uses or
enables a feature that requires it, such as:

- Configuring and calling an AI provider;
- Checking for updates;
- Cloud/WebDAV sync;
- Opening remote links.

## Data collection

BeeOffice does not include telemetry or analytics by default.

## Third-party services

If the user configures a third-party AI/cloud service, that service's privacy
policy applies to the data the user sends to it.
